# BPMN Desk

Пояснения и проектная документация — на русском. README.md — на английском, README.ru.md — русский перевод. GitHub release notes — английский текст и русский перевод в раскрываемом блоке. Основная платформа — Linux, формат поставки — AppImage; Windows — следующий поддерживаемый target, macOS — будущий.

- Работа автономная. Каждое завершённое изменение — отдельный локальный коммит. Пуш — только по запросу.
- Сообщения коммитов — на английском; документация и пояснения — на русском.
- Встроенные примеры должны иметь provenance и явную лицензию. Пользовательские схемы/provenance не включать в Git или дистрибутив; содержимое внешних пакетов не изменять.
- `src/desktop` отвечает за Electron, IPC и файловую систему.
- `src/shared` содержит только контракты, без Electron, React и Node runtime.
- `src/renderer/bpmn` изолирует bpmn-js, сериализацию и команды.
- `src/renderer/flowable` содержит расширения и описание форм Flowable.
- `src/renderer/documents` отвечает за жизненный цикл документов.
- UI не обращается к файловой системе напрямую, изменения модели проходят через command stack.
- Не использовать `any`, не отключать strict TypeScript. Новые зависимости обосновывать.
- Не делать большие универсальные компоненты: выделять самостоятельные обязанности.
- Архитектурные решения фиксировать в `docs/adr/`. Ограничения отражать в README.
- Перед коммитом запускать проверки, соответствующие изменению. Перед сдачей: `npm run check`, `npm run test:e2e`, `npm run package:linux`.
- Не объявлять Windows/macOS проверенными без запуска на этих ОС.
