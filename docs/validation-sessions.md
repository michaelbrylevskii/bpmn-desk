# Локальная проверка рабочих сессий и файлов

Ручная приёмка завершена 9 ноября 2026 года; выпуск 0.7.0 опубликован. Ниже сохранены результаты локальных итераций до выпуска. [Актуальная проверка релиза](validation.md).

## Расположение кнопки новой вкладки после 0.7.0

Локальное уточнение от 9 ноября 2026 года: плюс следует сразу за последней вкладкой, пока они помещаются, и остаётся справа при переполнении. Скрытые стрелки не занимают место. Проверена геометрия в браузере с одной и пятью вкладками, при сужении окна до 800 px и расширении до 1800 px. Решение уточнено в [ADR 0043](adr/0043-pinned-sessions-and-workspace-feedback.md).

`npm run check` прошёл: strict TypeScript, ESLint, 137 unit в 34 файлах. Полный `npm run test:e2e`: 126 passed, 19 ожидаемых skip; включая переполнение и перестановку вкладок, Electron и обе проверки AppImage. `npm run package:linux` собрал локальную AppImage с версией 0.7.0 и SHA-256 `ce6a73ee951c95220ba8791c7630a7a65fe6963cf444eca92cb40a235c4cd93d`. Эта сборка содержит локальную правку и отличается от опубликованного дистрибутива; пуш и новый релиз не выполнялись. Windows/macOS для уточнения не запускались.

## Открытие окон и меню от 2026-11-09

Уточнение [ADR 0042](adr/0042-session-windows.md): отдельное пустое окно из меню, по `Ctrl+Shift+N` и при повторном запуске без файла. Запуск с файлом использует последнее активное окно. В SVG, обоих PNG и «Сохранить как…» нативное меню использует многоточие `…`.

`npm run check` — strict TypeScript, ESLint и 137 unit-тестов успешно. `npm run package:linux` — AppImage x86_64 собрана. Полный `npm run test:e2e` — 126 passed, 19 ожидаемых skip за 4,8 минуты, включая 18 сценариев Electron и обе проверки AppImage. Пропуски — Windows и 18 сценариев отдельного движка. Отдельно прошли проверки CLI, нового окна через меню и нативное сочетание клавиш, а также повторного запуска executable из AppImage.

Проверяется сохранение несохранённой работы исходного окна, пустая стартовая страница в новом, несколько последовательных окон, независимое закрытие и смена языка меню. Запуск с файлом проверяется до и после создания нового окна; AppImage проверяет фактический повторный запуск упакованного executable, а не только вызов команды меню. Обычная активация значка панели задач зависит от рабочего окружения и не проверялась как запуск нового процесса.

SHA-256 сборки: `d020594ec5cc00f116eba1f5074fe112f402cba1c9f5d7d31a7a677f3b9c0006`. Запуск: `npm run dev` или `release/BPMN-Desk-0.6.1-x86_64.AppImage`. Версия остаётся 0.6.1; пуш и публикация не выполнялись. Ручная приёмка пользователя ожидается. Windows/macOS не запускались.

Просмотрены стартовая страница и подсказка сессии в светлой и тёмной темах. 1. Закрепить сессию, задать имя в строке, отменить и повторить переименование. Сверить имя в списке и предложении восстановления. Проверить подсказки схем и мониторов, открепление и отдельное удаление.

## Ручная проверка

Запуск из исходников: `npm run dev`. Локальная сборка: `release/BPMN-Desk-0.6.1-x86_64.AppImage`.

SHA-256 этой локальной AppImage: `d9c56cd63b910e48730da1b5d06360562bf306c0c7bc611d21995ad2d14e5045`.

1. Открыть несколько схем и мониторов, изменить схему и оставить XML без применения. Переставить вкладки, закрыть приложение и восстановить сессию; сравнить содержимое, выбор и активную вкладку.
2. Скрыть предложение восстановления, перезапустить приложение, затем восстановить запись из списка сессий. Проверить удаление записей обоих списков и доступность примеров из меню создания.
3. При открытых вкладках восстановить другую сессию: появляется отдельное окно, исходная работа сохраняется. Повторное открытие той же сессии переводит фокус в её окно.
4. Изменить и удалить открытый файл внешним редактором, проверить жёлтый и красный статусы с подсказками. Попробовать перезагрузку и все варианты сохранения при конфликте.
5. Проверить контекстное меню вкладок и меню по Alt, в том числе команды в разных окнах, обе темы и локализации.

Ручная приёмка пользователя ожидается. Windows/macOS в этой доработке не запускались. История undo между запусками и перенос фигур между окнами не сохраняются; буфер фигур общий для вкладок одного окна. Browser-preview использует localStorage с ограничениями браузера; проверка файлов и нативных окон выполняется в Electron. Пользовательские схемы и подключения не входят в Git или дистрибутив.
