Общий runtime-прогон дал 49 passed и один сбой устаревшего тестового селектора стартовой страницы; проверка переведена на меню подключений. Повтор `npm run test:runtime -- tests/e2e/runtime.spec.ts --grep 'подключения: несколько'` — 1 passed. Код приложения при уточнении теста не менялся. Повторный `npm run check` также успешен.

Покрытие сессий: чистые и изменённые документы, порядок и активная вкладка, 21 фоновая схема, неприменённый XML, выбор и масштаб, изменения расширений и сохранение после восстановления. Проверяются миграция recovery, устойчивое скрытие предложения, удаление снимка с подтверждением и ограничение 15 записей. Ошибка чтения хранилища не разрешает его перезапись; ошибка записи при закрытии позволяет вернуться к документам.

Файловые сценарии включают изменение, возврат к прежнему содержимому, удаление и повторное создание, подтверждения отмены/копии/перезаписи, повторную проверку ревизии и сохранение модели при некорректном внешнем XML. Запись копии поверх уже открытого файла не меняет основу исходной вкладки: она получает внешний статус и предупреждение при сохранении. Меню проверяются клавиатурой и мышью; native copy/paste сохраняет отдельную отмену в целевой вкладке.

Несколько окон: восстановление из занятого окна, фокусировка уже открытой сессии, независимое закрытие, изоляция файловых tokens и команд меню, общие подключения с секретом в памяти, язык и тема. Изменение общего файла в одном окне обнаруживается другим. Мониторы восстанавливают фильтры и место просмотра, получают свежие ответы API; скрытый восстановленный монитор не загружается до открытия.

## Ручная проверка

Запуск из исходников: `npm run dev`. Локальная сборка: `release/BPMN-Desk-0.6.1-x86_64.AppImage`.

SHA-256 этой локальной AppImage: `d9c56cd63b910e48730da1b5d06360562bf306c0c7bc611d21995ad2d14e5045`.

1. Открыть несколько схем и мониторов, изменить схему и оставить XML без применения. Переставить вкладки, закрыть приложение и восстановить сессию; сравнить содержимое, выбор и активную вкладку.
2. Скрыть предложение восстановления, перезапустить приложение, затем восстановить запись из списка сессий. Проверить удаление записей обоих списков и доступность примеров из меню создания.
3. При открытых вкладках восстановить другую сессию: появляется отдельное окно, исходная работа сохраняется. Повторное открытие той же сессии переводит фокус в её окно.
4. Изменить и удалить открытый файл внешним редактором, проверить жёлтый и красный статусы с подсказками. Попробовать перезагрузку и все варианты сохранения при конфликте.
5. Проверить контекстное меню вкладок и меню по Alt, в том числе команды в разных окнах, обе темы и локализации.

Ручная приёмка пользователя ожидается. Windows/macOS в этой доработке не запускались. История undo между запусками и перенос фигур между окнами не сохраняются; буфер фигур общий для вкладок одного окна. Browser-preview использует localStorage с ограничениями браузера; проверка файлов и нативных окон выполняется в Electron. Пользовательские схемы и подключения не входят в Git или дистрибутив.
