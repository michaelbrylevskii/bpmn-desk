# Проверка фонового поиска обновлений

Локальная доработка после 0.7.1. Дата: 2026-11-10. Решение: [ADR 0044](adr/0044-release-checks.md).

## Объём

- Проверка последнего стабильного релиза при запуске собранного приложения и каждые шесть часов; одно состояние для всех окон.
- Оранжевый номер установленной версии, подсказка с доступной версией и открытие фиксированной страницы релизов в системном браузере.
- Ошибки, HTTP-ограничения, некорректный ответ и десятисекундный таймаут возвращают серый бейдж без уведомлений.
- Ни загрузки установщика, ни установки, ни перезапуска приложения. Разработка и browser-preview по умолчанию не опрашивают GitHub.

## Сценарии

Unit-тесты используют изолированный транспорт и виртуальные часы. Проверяются числовое сравнение версий, одинаковые и более старые релизы, prerelease и draft, неправильные теги и поля, стартовый запрос и шестичасовой интервал, подписки окон, отсутствие повторных публикаций одинакового статуса, ошибки сети/HTTP/JSON/размера, восстановление после ошибки, таймаут заголовков и тела и остановка сервиса.

Chromium проверяет установленный номер в интерактивном бейдже, обе темы, доступность при узком окне, английскую и русскую подсказки, фокус, Escape, активацию Enter, серое состояние без уведомлений и приоритет события над запоздавшим начальным snapshot.

Electron запускает настоящий main/preload/renderer с тестовым entrypoint. На границе подменяются только транспорт GitHub и открытие системного браузера. Пока запрос удерживается, открываются два рабочих окна. После ответа оба показывают одинаковое обновление; второй запуск окна не создаёт второй запрос. Подставной `html_url` игнорируется: браузеру передаётся только фиксированная HTTPS-страница текущего репозитория. Тестовые файлы не входят в ASAR.

## Результаты

| Команда | Результат |
| --- | --- |
| `npm run check` | TypeScript, ESLint; 164 unit-теста в 35 файлах прошли |
| `npm run test:e2e` | 132 прошли, 19 штатных пропусков; Chromium, Electron, извлечённая AppImage и локальные API fixtures |
| `npm run package:linux` | Linux x86_64 AppImage собран |
| `git diff --check` | Без ошибок |

Предварительный прогон прерван во время доработки тестового entrypoint и пересборки; итоговый полный прогон выполнен отдельно, без параллельного запуска E2E или изменения сборки.

Для ручного dev-запуска проверена переменная `VITE_BPMN_DESK_DEV_VERSION=0.0.0`: Electron и Vite с отдельным временным профилем показали `0.0.0` в шапке, настоящий GitHub API вернул доступный релиз `0.7.1`, оранжевый бейдж отобразился. `package.json` не менялся. Команда и границы режима описаны в [разработке](development.md).

Артефакт: `release/BPMN-Desk-0.7.1-x86_64.AppImage`. Это локальная сборка с доработкой, а не опубликованный артефакт 0.7.1. SHA-256: `76f972de8609bf0e92ac53059c615eec2499916643d2a1cdfd16bbc7f4ab2b72`.

Windows и macOS в этом локальном прогоне не проверялись.
