# Проверка версии 0.2.0

Дата: 2026-10-09. Среда: Linux x86_64, Manjaro, kernel 6.18.44; Node.js 26.7, Electron 44.7, Flowable 7.2. Windows-пакеты собраны через Docker `electronuserland/builder:24-wine` с закреплённым digest.

## Выполнено

- Strict TypeScript, ESLint и 39 unit-тестов: XML roundtrip пяти встроенных схем, кастомные расширения, сохранность при rename/undo, DI, XML-навигация, SVG, размещение событий, атомарная запись/конфликты, настройки языка, provenance и SHA-256, безопасные пути/повторы/полнота внешнего пакета, UTF-8 и проверка происхождения дополнительных экспортов. Новые регрессии: восстановление более двадцати документов и запрет пересечения входного пакета с каталогами результатов, включая ссылки.
- 26 E2E прошли: свойства/Flowable, undo/redo, сохранение всех встроенных примеров, расширения, вкладки/recovery, ошибочный XML, definitions/listeners/fields, подпроцесс, языки, тема/DI/SVG, XML-поиск/замена/выделение, native preload/CLI/single instance/save/conflict/close/zoom/menu, извлечённая AppImage. Новый сценарий восстанавливает 21 изменённую вкладку и открывает ранее скрытые диаграммы. Включена проверка, что dev-сервер возвращает 403 для `.cache/` и `.local-schemas/`. Windows runtime-тест пропущен на Linux: **26 passed, 1 skipped**.
- Официальный Flowable converter 7.2 подтвердил исполняемую модель всех пяти встроенных экспортов и отдельного экспорта `boundary-events` после исправления размещения. DI исключён из сравнения; координаты проверяются UI-тестами.
- Отдельный локальный пакет: пять исходных схем прошли двойной roundtrip, пять UI-открытий/сохранений и независимое сравнение Flowable. Входные файлы и provenance сохранили контрольные суммы. Их содержимое не входит в основной набор или дистрибутив.
- Дополнительная схема с кириллическим именем без DI: roundtrip и Flowable прошли, UI явно пропущен. Receipt не позволяет конвертеру принять результаты другого пакета или изменённый экспорт.
- Три upstream-примера скопированы без изменения XML, revision и SHA закреплены; две оригинальные схемы имеют MIT. Пересняты три preview на встроенной `flowable-showcase`.
- Linux AppImage и Windows NSIS/portable собраны. ASAR содержит main/preload/renderer, MIT LICENSE и THIRD_PARTY_NOTICES; resources содержат полный текст Apache-2.0 и ровно пять встроенных схем с provenance. Копии и лицензия побайтово сверены. В runtime нет внешнего пакета, его runner или исходных пользовательских схем.
- Внешние NSIS-архивы и вложенные 7z проверены на целостность; installer и portable содержат одинаковый payload. Новые EXE не подписаны.
- Текущие отслеживаемые файлы очищены от организационных идентификаторов и прежних примеров. Проверен `git diff --check`. Публичная история начинается с нового root-коммита очищенного состояния; прежняя история сохраняется отдельно локально.
- Чистый снимок через `git archive`: `npm ci`, `setup:electron`, `check` и `build` прошли без копирования локальных зависимостей или пользовательских пакетов. npm 12 заблокировал install scripts двух esbuild и electron-winstaller; сборка работает с установленными пакетными бинарниками, ручное разрешение этих скриптов не потребовалось.
- Windows повторно собран штатной командой `npm run package:windows:docker` из текущего каталога. После переноса потребовалось разрешить путь проекта в File sharing Docker Desktop и освободить место неиспользуемых ресурсов.

## Проверка GitHub Actions

[Успешный прогон 37937481261](https://github.com/michaelbrylevskii/bpmn-desk/actions/runs/37937481261) на коммите `dcb129d`: Ubuntu 24.04 — 39 unit и 26 E2E с одним Windows skip; Windows Server 2022 — 37 unit с двумя skip для symlink и 26 E2E, включая собранный EXE. Обе платформы выполнили независимую проверку Flowable и сохранили свои сборки. 2026-10-09 пользователь подтвердил работу опубликованной 0.2.0 через Windows-инсталлятор. Версия ОС, portable, удаление и ассоциации отдельно не подтверждены.

## Аудит зависимостей

Перед первой публикацией добавлены и проверены actionlint конфигурация GitHub Actions, три unit-теста manifest релиза и обновлённая иконка с ISC notice Lucide. Успешность удалённых CI-прогонов фиксируется отдельно; локальный отчёт сам по себе её не подтверждает.

`npm audit --omit=dev` не обнаружил уязвимостей. Полный `npm audit` сообщил **8 moderate, 0 high, 0 critical**: одна проблема `sprintf-js` распространяется на зависимости сборочного electron-builder через roarr/global-agent/@electron/get. [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) описывает отказ в обслуживании при неконтролируемой точности форматирования; опубликованной исправленной версии sprintf-js в advisory нет.

Эта цепочка не входит в `app.asar`. Предложенный npm откат electron-builder с 26.15.3 на 26.5.0 не применён: он меняет проверенный набор инструментов упаковки, а исправления самого sprintf-js нет. Полный аудит не считается чистым; его нужно повторять перед следующей поставкой.

## Границы проверки

В среде нет `/dev/fuse`: AppImage проверена после извлечения с включённым Chromium sandbox. Для запуска без FUSE используется `--appimage-extract-and-run` первым аргументом.

Локальная проверка выполнена на Linux. Нативный runtime отдельно проверен на Windows Server 2022 в CI; работа релизной сборки через Windows-инсталлятор дополнительно подтверждена пользователем 2026-10-09; версия ОС и отдельные сценарии удаления/ассоциаций не указаны. Инструкция: [windows.md](windows.md). macOS пока не входит в поставку. Конвертер не исполняет Java delegates или expressions и не подтверждает бизнес-результат процесса.
