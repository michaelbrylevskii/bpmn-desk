# BPMN Desk 0.3.0

Добавлена поддержка Camunda 7 и доработаны создание схем, экспорт изображений, XML и настройки интерфейса. Поддержка Flowable сохранена.

## Новое

- Выбор Flowable, Camunda 7 или BPMN 2.0 при создании схемы; профиль открытого файла определяется по URI namespace.
- Формы Camunda 7: external tasks, async, listeners/fields, input/output parameters, map/list/script, formData, connectors, in/out, DMN/call bindings, события и multi-instance. Неизвестные атрибуты и расширения сохраняются; альтернативные префиксы поддержаны.
- Два встроенных примера Camunda 7. Все семь примеров имеют префикс движка, provenance и явную лицензию.
- Экспорт через общее меню: SVG, PNG с белым фоном или прозрачностью. PNG строится из всей схемы в масштабе 2×; экспорт не сохраняет изменения BPMN.
- Системная, светлая и тёмная тема; выбор сохраняется, системная тема обновляется без перезапуска. Выбор языка приведён к стилю соседних инструментов.

## Исправления

- Полная отмена названия восстанавливает исходную DI подписи, её координаты и стиль; ложный индикатор несохранённых изменений устранён.
- Copy/paste и смена типа задачи сохраняют расширения обоих движков; глобальные Camunda ID при вставке получают уникальные значения.
- Кнопка поиска XML открывает и закрывает панель, сохраняя запрос. XML расширений имеет собственные отступы без изменения текста/CDATA и значимых пробелов.
- Ошибка применения XML прямо сообщает об отказе; подробности парсера раскрываются отдельно. Ошибки имеют красное оформление, успешные действия — значок с галочкой.
- Уведомления затухают и закрываются автоматически; наведение, фокус и открытые подробности приостанавливают таймер. Возобновление имеет задержку 1,5 секунды.
- Фокус холста использует акцент приложения в обеих темах; постоянная надпись Offline убрана.

## Дистрибутивы

- `BPMN-Desk-0.3.0-x86_64.AppImage` — Linux x86_64.
- `BPMN-Desk-0.3.0-x64-Setup.exe` — установщик Windows x64.
- `BPMN-Desk-0.3.0-x64-Portable.exe` — Windows x64 без установки.
- `SHA256SUMS` — контрольные суммы трёх файлов.

Node.js и Java для запуска приложения не нужны. Linux: `chmod +x BPMN-Desk-0.3.0-x86_64.AppImage`; при отсутствии FUSE — первый аргумент `--appimage-extract-and-run`. Релизные файлы собираются и проверяются в GitHub Actions; ссылка на конкретный прогон добавляется при публикации.

## Проверки и границы

Локальный Linux-прогон: 63 unit-теста, 58 E2E и одна пропущенная Windows-проверка; AppImage собрана и запущена. Официальные Flowable converter 7.2 и Camunda BPMN Model API 7.24 проверяют экспорты схем. Матрица релиза отдельно запускает Linux и Windows перед публикацией; полный протокол находится в `docs/validation.md` репозитория.

Целевая спецификация расширений — Camunda 7.24; Camunda 8/Zeebe не поддерживается. Редактор не выполняет процессы, scripts/delegates и deployment; DMN/CMMN и внешние формы не редактируются. Для визуального редактирования нужен BPMN DI; автоматической раскладки нет. PNG ограничен стороной 16 384 px, площадью 32 млн пикселей и файлом 20 МБ; для крупных схем доступен SVG.

Windows EXE не подписаны; автоматический запуск в CI не заменяет ручную проверку установки и ассоциаций. macOS пока не поставляется. Код приложения и оригинальные примеры — MIT; заимствованные примеры Flowable — Apache-2.0, символ иконки Lucide — ISC. Лицензии включены в дистрибутивы.
