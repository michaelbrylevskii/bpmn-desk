# BPMN Desk 0.3.0

- Поддержка Camunda 7: external tasks, listeners, input/output, forms, connectors, in/out, DMN/call bindings и multi-instance.
- Выбор профиля новой схемы, namespace detection и семь лицензированных примеров.
- PNG с белым/прозрачным фоном, системная тема и улучшения XML-поиска.
- Исправления dirty state, undo DI, copy/paste, отступов XML расширений и уведомлений.

AppImage, Windows installer/portable и `SHA256SUMS` собраны и проверены в [GitHub Actions](https://github.com/michaelbrylevskii/bpmn-desk/actions/runs/37992511168).

Camunda 8/Zeebe, редактирование DMN/CMMN и исполнение процессов не включены. Windows EXE не подписаны, macOS не поставляется. [Релиз](https://github.com/michaelbrylevskii/bpmn-desk/releases/tag/v0.3.0).
