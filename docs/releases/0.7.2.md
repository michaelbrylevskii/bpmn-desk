# BPMN Desk 0.7.2

- Проверка новых релизов GitHub при запуске и каждые шесть часов. Оранжевый бейдж версии открывает последний релиз; установка выполняется вручную.
- Серая кнопка версии запускает ручную проверку. Анимация длится минимум секунду, в подсказке показаны результат и время последней проверки. Ошибки сети и таймауты остаются в подсказке, не прерывая работу.
- Клик по логотипу открывает сведения об авторе, ссылки автора и проекта, лицензию, версию и техническую информацию.

Доступны Linux AppImage, Windows installer/portable и `SHA256SUMS`. Windows EXE не подписаны; macOS не поставляется.
