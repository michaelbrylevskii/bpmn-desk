# BPMN Desk 0.7.1

- Кнопка новой вкладки находится сразу после последней, пока вкладки помещаются, и остаётся видимой справа при переполнении.
- Прокрутка вкладок без рывков у краёв: стрелки расположены поверх зон затухания и не меняют доступную ширину. Работают обычное колёсико, горизонтальная прокрутка и Shift.
- Средняя кнопка мыши закрывает вкладку с обычным подтверждением для несохранённых изменений.
- Обновлены скриншоты README: главный кадр со сплитом светлой и тёмной тем, стартовая страница, монитор и история выполнения.

Доступны Linux AppImage, Windows installer/portable и `SHA256SUMS`. Windows EXE не подписаны; macOS не поставляется.
