# BPMN Desk 0.7.0

- **Восстановление рабочего пространства.** Схемы и мониторы возвращаются вместе с порядком вкладок, активной вкладкой, содержимым схем, неприменённым XML, выделением и положением холста. Хранятся 15 недавних сессий; именованные закрепления не входят в этот лимит.
- **Несколько окон.** «Файл → Новое окно» (`Ctrl+Shift+N`) или повторный запуск без файла создаёт отдельное окно. Восстановление сессии из занятого окна открывает другое; уже открытая сессия переводит фокус в своё окно. Запуск с файлом использует активное окно.
- **Изменения на диске.** Индикаторы вкладок и подсказки различают локальные правки, внешние изменения и конфликты. Доступны перезагрузка с диска, сохранение отдельной копии, подтверждение перезаписи и повторное создание удалённого файла без молчаливой замены схемы.
- **Вкладки и недавняя работа.** Меню вкладки включает дублирование, перезагрузку, показ файла в папке и массовое закрытие. Переполненные вкладки прокручиваются стрелками, края затухают, кнопка новой вкладки остаётся видимой. Главная объединяет сессии и недавние файлы с компактными действиями открытия схем и мониторов.
- **Доступ к результатам экспорта.** После SVG и PNG появляется уведомление с кнопкой «Показать в папке». Нативное меню содержит PNG с белым и прозрачным фоном; названия команд с диалогом оформлены единообразно.

Восстанавливаются снимки документов, но не Undo/Redo и цепочки навигации. Мониторы заново читают данные; секреты подключений не входят в снимки сессий. Закреплённая сессия обновляется при работе после её восстановления. Клик по значку панели задач может только фокусировать существующее окно — это зависит от рабочего окружения.

AppImage, Windows installer/portable и `SHA256SUMS` собирает и проверяет GitHub Actions. Windows EXE не подписаны; macOS не поставляется.
