# BPMN Desk 0.6.0

- **История выполнения Flowable с привязкой к схеме.** Поиск завершённых и продолжающихся экземпляров, отдельные проходы шагов, циклы, параллельные multi-instance и вызванные процессы на точной развёрнутой версии BPMN. Выбор записи журнала находит элемент схемы, выбор элемента фильтрует его проходы. Доступны время, исполнители, причины прекращения и сохранённые переменные с областями task/execution.
- **Текущее состояние и история на одном холсте.** Схема совмещает зафиксированные проходы и подтверждённые runtime-позиции. Вкладки **Текущее состояние** и **История выполнения** справа переключают подробности, сохраняя масштаб и выбор на схеме. Runtime и история доступны независимо при отказе другого API; экспорт SVG/PNG включает совмещённые метки.
- **Навигация между связанными процессами.** Карточки родителя и ребёнка показывают название схемы, business key/имя и ID экземпляра. Кнопки назад/вперёд в тулбаре монитора содержат подсказки назначения; поддержаны команды боковых кнопок мыши Linux и Windows. У каждого монитора своя история переходов.
- **Больше места для схемы.** Обе панели независимо сворачиваются нижними язычками. Выбор другого элемента оставляет подробности скрытыми и мягко отмечает язычок как обновлённый. Легенда и время снимков занимают по строке; пояснения доступны в подсказках по наведению и фокусу.
- **Исправления управления холстом.** Вертикальная/горизонтальная прокрутка и масштабирование колёсиком работают над бейджами. Логотип bpmn.io целиком виден рядом с язычком и не перекрывает его. Повторный выбор открытого dead-letter задания возвращает к подробностям ошибки.

Для истории нужны сохранённые данные Flowable и доступ к API. Отсутствие времени окончания не подтверждает активность шага, а зафиксированное окончание не доказывает успех. Неполные результаты обозначаются явно; сохранённые переменные содержат последние записанные значения, а не значения на выбранном проходе. Маршрут подсвечивается только по записанным sequence flows. Навигация хранит до 100 адресов в каждом направлении в памяти каждого монитора.

AppImage, Windows installer/portable и `SHA256SUMS` собирает и проверяет GitHub Actions. Windows EXE не подписаны; ручная приёмка установщика не подтверждена. macOS не поставляется.
