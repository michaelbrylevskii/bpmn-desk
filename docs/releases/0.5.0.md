# BPMN Desk 0.5.0

- **Копирование между схемами одного окна.** Общий буфер сохраняет выделенные группы, связи, подпроцессы, граничные события и расширения Flowable/Camunda 7. История отмены и повтора остаётся отдельной у каждой схемы; буфер доступен и после закрытия вкладки-источника.
- **Сохранение определений при вставке.** Ошибки, сообщения, сигналы и эскалации переносятся с разрешением конфликтов ID. Повторная вставка из того же буфера использует уже перенесённые определения.
- **Перестановка вкладок.** Перетаскивай вкладки схем, мониторов и стартовой страницы либо используй **Ctrl+Shift+←/→** при фокусе на вкладке. Содержимое, выбранная вкладка и история команд сохраняются.
- **Поток по умолчанию в свойствах стрелки.** Выбери стрелку → **Основные · BPMN** → **Поток по умолчанию**. Поле меняет стандартный `default` исходной задачи/шлюза; прежний выбор у узла остаётся доступен. Список исходящих стрелок теперь работает и без явных `outgoing` в XML.

Для переноса выдели элементы на холсте, нажми **Ctrl+C**, переключись на другую схему, щёлкни по свободному месту холста, нажми **Ctrl+V** и укажи место вставки. Буфер действует внутри одного окна; внешние процессы, формы и ресурсы автоматически не переносятся. Порядок вкладок действует до закрытия окна.

Используется стандартный BPMN `default="ID_стрелки"`, поддерживаемый Flowable и Camunda 7. Дополнительный `flowable:is-default-flow` не создаётся и не трактуется как замена `default`; существующий XML внутри расширений сохраняется.

AppImage, Windows installer/portable и `SHA256SUMS` собирает и проверяет GitHub Actions. Windows EXE не подписаны; ручная приёмка установщика не подтверждена. macOS не поставляется.
