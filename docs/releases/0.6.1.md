# BPMN Desk 0.6.1

- **Единые каталоги и фильтры монитора.** Определения по умолчанию показывают последние версии. Текущие экземпляры и история разделены на каталоги с компактными сворачиваемыми фильтрами и снимаемыми чипами. Переход к экземплярам определения задаёт один общий контекст отдельного цвета для Runtime, History и dead-letter; его снятие убирает контекст сразу везде.
- **Сохраняемый переключатель сводки с приоритетом схемы.** Выделенная кнопка управляет сводкой во всём приложении и помнит состояние после перезапуска. Чтение начинается после отображения выбранной схемы, использует таймаут API подключения и участвует в авторефреше. Неизменившиеся данные сохраняют выбор, масштаб, прокрутку и DOM бейджей; обновление настроек подключения также сохраняет холст.
- **История рядом с runtime в сводке определения.** Подробности элемента разделены на вкладки Runtime и History. Сводка читает до 100 executions, 100 dead-letter jobs и 1000 свежих исторических шагов, независимо считая разные экземпляры каждого источника. Неполные значения оформлены как `17+`; нижняя граница поясняется в подсказке. Ошибка одного источника не скрывает остальные.
- **Читаемые бейджи на плотных схемах.** Один бейдж объединяет серую историю, зелёный runtime и красные ошибки секциями с зигзагами. Известный runtime-счётчик сохраняется рядом с ошибками. Метки автоматически обходят соседние фигуры, подписи и другие бейджи; тонкие линии показывают принадлежность элементам. SVG/PNG сохраняют секции, позиции и линии привязки.
- **Понятнее подробности и работа с журналом.** Правая панель определения сохраняет место и показывает плейсхолдер без выбранного элемента. Общие поля экземпляра имеют единый порядок в Runtime и History, ID определения ведёт к точной версии. Вся панель прокручивается целиком, не сжимая журнал в узкую вложенную область. Раскрытие записи журнала оставляет остальные записи видимыми; выбор элемента схемы по-прежнему фильтрует его историю.
- **Выделение и XML.** Выбранный элемент монитора получает заметную рамку в стиле редактора. XML монитора доступен с подсветкой и поиском только для чтения; контролы замены скрыты. Переходы между определением и экземплярами находятся рядом с названием и версией схемы, подсказка сводки больше не дублирует легенду холста.

Сводка использует ограниченные выборки, не является полным аудитом или точным глобальным количеством экземпляров. Исторические счётчики могут пересекаться с runtime, зафиксированное окончание не доказывает успех. На плотных схемах линии привязки бейджей могут пересекать стрелки. Данные движка не изменяются.

AppImage, Windows installer/portable и `SHA256SUMS` собирает и проверяет GitHub Actions. Windows EXE не подписаны; ручная приёмка установщика не подтверждена. macOS не поставляется.
