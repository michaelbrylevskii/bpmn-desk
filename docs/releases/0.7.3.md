# BPMN Desk 0.7.3

- Серая точка отмечает вкладки схем без файла; правки меняют её на синюю, Undo возвращает исходное состояние. Новые схемы, дубликаты и копии из монитора требуют подтверждения закрытия.
- У дубликата собственное исходное состояние, включая скопированный XML-черновик. Восстановление сессии сохраняет индикацию правок.
- Исправлен остаточный XML-черновик после полной отмены XML-правок, который мог блокировать сохранение последующих изменений схемы.
- Сохранение, дублирование, перезагрузка и закрытие учитывают незавершённый ввод в свойствах. Подсказки вкладок единообразно описывают состояние схемы и файла на русском и английском.

Доступны Linux AppImage, Windows installer/portable и `SHA256SUMS`. Windows EXE не подписаны; macOS не поставляется.
