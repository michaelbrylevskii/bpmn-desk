# BPMN Desk 0.4.0

- Монитор Flowable REST 7.2: определения, экземпляры, executions, задачи и переменные; только чтение.
- Dead-letter jobs со stacktrace и подсветкой; переходы между родительскими и дочерними экземплярами.
- Ограниченная сводка версии, фильтры, пагинация, независимые мониторы и экспорт меток в SVG/PNG.
- Единая стартовая страница, меню профилей BPMN/Flowable/Camunda 7 и общие настройки подключений.
- Сохранность черновиков и канонический путь файла при повторном открытии; цельный переключатель языка.

AppImage, Windows installer/portable и `SHA256SUMS` собраны в [GitHub Actions](https://github.com/michaelbrylevskii/bpmn-desk/actions/runs/38060956883). На каждой ОС прошли 65 E2E и 13 runtime-сценариев; unit — 84 на Linux и 82 с двумя symlink skip на Windows.

Монитор не включает административные действия, history и runtime Camunda 7. Windows EXE не подписаны; ручная приёмка установщика не подтверждена. macOS не поставляется. [Релиз](https://github.com/michaelbrylevskii/bpmn-desk/releases/tag/v0.4.0).
