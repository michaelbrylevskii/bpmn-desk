# BPMN Desk 0.4.0

Монитор состояния Flowable дополняет локальный редактор BPMN, Flowable и Camunda 7. Просмотр серверов работает в независимых вкладках и предоставляет только чтение.

## Новое

- Сохранённые подключения к Flowable REST 7.2 с авторизацией none, Basic и Bearer. Проверка полей подключения доступна до сохранения. Секрет можно оставить в памяти сессии или сохранить через защищённое хранилище ОС.
- Развёрнутые определения, точная версия схемы для запущенного экземпляра, executions, user tasks, переменные процесса и локальные переменные execution. Поддержаны переходы к родительскому и дочерним экземплярам.
- Отдельный каталог dead-letter jobs, красная подсветка места ошибки, счётчики, сообщение и stacktrace. Из карточки экземпляра можно перейти к его заданиям с ошибками.
- Ограниченная сводка выбранной версии: два запроса, до 100 executions и 100 dead-letter jobs, таймаут 8 секунд. Неполные значения показаны как `≥ N`, недоступные данные — как недоступные. Связанные экземпляры открываются из выбранного элемента сводки.
- Фильтры, сортировка, пагинация и серверный выбор последних версий. Ручное и автоматическое обновление сохраняют положение холста и выбор элемента.
- Несколько мониторов рядом с документами; создание локальной копии развёрнутой схемы. Экспорт SVG/PNG монитора включает метки состояния.

## Интерфейс

- Главная страница и обычная вкладка «Новая вкладка» предлагают одинаковые действия: файлы, создание схемы с выбором профиля, монитор, примеры и недавние файлы.
- Успешное открытие заменяет стартовую вкладку; отмена и ошибка сохраняют её. Открытый файл активируется без потери черновика и undo.
- Управление подключениями доступно в общем тулбаре из любой вкладки. Сохранение, проверка и удаление профиля находятся в одном ряду.
- Переключатель языка — одна кнопка с кликабельным глобусом и одной рамкой фокуса. Холст монитора и редактора используют общий акцент; длинные идентификаторы переносятся внутри панелей.
- Открытие и сохранение используют одинаковый канонический путь: повторное открытие недавнего файла активирует черновик и при разных представлениях пути на Windows.
- Системное меню скрыто до нажатия Alt; сочетания клавиш продолжают работать.

## Дистрибутивы

- `BPMN-Desk-0.4.0-x86_64.AppImage` — Linux x86_64.
- `BPMN-Desk-0.4.0-x64-Setup.exe` — установщик Windows x64.
- `BPMN-Desk-0.4.0-x64-Portable.exe` — Windows x64 без установки.
- `SHA256SUMS` — контрольные суммы трёх файлов.

Node.js и Java для запуска приложения не нужны. Linux: `chmod +x BPMN-Desk-0.4.0-x86_64.AppImage`; без FUSE используй первым аргументом `--appimage-extract-and-run`. Артефакты собраны и проверены в [GitHub Actions](https://github.com/michaelbrylevskii/bpmn-desk/actions/runs/38060956883).

## Проверки и границы

Локальная проверка Linux: strict TypeScript, ESLint, 84 unit-теста, 65 общих E2E и 13 сценариев на независимом Flowable 7.2/H2. AppImage запускается с sandbox; официальные Flowable converter 7.2 и Camunda Model API 7.24 проверяют сохранённые модели. Нативная матрица прошла на Linux и Windows: 65 E2E и 13 runtime-сценариев на каждой ОС; 84 unit-теста на Linux и 82 с двумя symlink skip на Windows. [Протокол проверки](https://github.com/michaelbrylevskii/bpmn-desk/blob/v0.4.0/docs/validation.md).

Монитор не выполняет deployment, retry или другие административные действия. Завершённые экземпляры и история, runtime Camunda 7, OAuth/SSO и сериализованные Java-переменные не включены. Снимок не транзакционен, сводка ограничена и обновляется по запросу. Локальные документы остаются на устройстве. Авторизацию и запросы к выбранному REST API выполняет Electron main.

Windows EXE не подписаны; автоматический запуск не заменяет ручную приёмку установщика и ассоциаций. macOS пока не поставляется. Код и оригинальные примеры — MIT; заимствованные примеры Flowable — Apache-2.0, символ иконки Lucide — ISC.
