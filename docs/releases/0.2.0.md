Первый публичный выпуск BPMN Desk — локального редактора BPMN 2.0 с расширениями Flowable.

- Редактирование схем, BPMN/Flowable-свойств, пользовательских атрибутов и XML расширений.
- Вкладки, undo/redo, восстановление несохранённых документов и защита от внешних изменений файла.
- XML с поиском, заменой и переходом к выбранному элементу схемы.
- Английский и русский интерфейсы, светлая и тёмная темы, масштаб интерфейса и схемы, экспорт SVG.
- Пять встроенных примеров с источниками и лицензиями; дополнительные пользовательские наборы остаются локальными.

## Файлы

- `BPMN-Desk-0.2.0-x86_64.AppImage` — Linux x86_64.
- `BPMN-Desk-0.2.0-x64-Setup.exe` — установщик Windows x64.
- `BPMN-Desk-0.2.0-x64-Portable.exe` — Windows x64 без установки.
- `SHA256SUMS` — контрольные суммы трёх файлов.

Node.js и Java для запуска приложения не нужны. На Linux сделай AppImage исполняемой: `chmod +x BPMN-Desk-0.2.0-x86_64.AppImage`. Без FUSE используй первым аргументом `--appimage-extract-and-run`.

## Ограничения

Сборки не подписаны сертификатом издателя. Автоматические проверки Windows не заменяют ручную проверку установки, удаления и ассоциаций на Windows 10/11. macOS пока не поставляется.

Для визуального редактирования нужны координаты BPMN DI; автоматической раскладки нет. Процессы, expressions и Java delegates не исполняются. Исходный XML может менять форматирование при сохранении. Подробности — в README и docs/validation.md.

Код приложения — MIT. Заимствованные примеры Flowable — Apache-2.0; символ иконки Lucide — ISC. Лицензии включены в дистрибутивы.
