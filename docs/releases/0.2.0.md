# BPMN Desk 0.2.0

- Визуальный редактор BPMN 2.0, свойства Flowable, пользовательские атрибуты и XML расширений.
- Вкладки, undo/redo, recovery и защита от внешних изменений файлов.
- XML-поиск и переход к элементу, EN/RU, две темы, масштабирование и SVG.
- Пять лицензированных примеров и дополнительные локальные тестовые пакеты.

AppImage, Windows installer/portable и `SHA256SUMS` собраны в GitHub Actions. [Проверки](https://github.com/michaelbrylevskii/bpmn-desk/blob/v0.2.0/docs/validation.md).

Для визуального редактирования нужен BPMN DI. Процессы не исполняются. Windows EXE не подписаны, macOS не поставляется. [Релиз](https://github.com/michaelbrylevskii/bpmn-desk/releases/tag/v0.2.0).
