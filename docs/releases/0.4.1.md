# BPMN Desk 0.4.1

- Таймаут каждого подключения: **5–120 секунд**, включая чтение ответа. Старые профили сохраняют значение по умолчанию **15 секунд**.
- Ошибка обновления каталога сохраняет предыдущую страницу с явной пометкой. Смена подключения, фильтров или страницы скрывает предыдущий результат; поздние ответы игнорируются.
- При таймауте списка предлагается сузить фильтры или увеличить время ожидания в **Управлении подключениями**. Автоматических повторов нет.
- Сводка версии сохраняет общий предел **8 секунд**.

Для медленного подключения можно установить **30–60 секунд**. Flowable REST 7.2 по-прежнему считает общее количество внутри запроса списка; этот релиз не устраняет и не оптимизирует серверный count.

AppImage, Windows installer/portable и `SHA256SUMS` собирает и проверяет GitHub Actions. Windows EXE не подписаны; ручная приёмка установщика не подтверждена. macOS не поставляется.
