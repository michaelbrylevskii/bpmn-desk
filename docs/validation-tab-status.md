# Проверка состояний документов и вкладок

Локальная доработка после 0.7.2, 12 ноября 2026 года. Правила: [ADR 0041](adr/0041-sessions-and-external-files.md), [ADR 0046](adr/0046-document-change-baselines.md).

## Поведение

- Новая схема, дубликат и локальная копия из монитора начинают с серой точки. Скопированная модель и неприменённый XML образуют исходное состояние дубликата независимо от правок источника. Дальнейшие правки дают синюю точку; Undo возвращает исходную, Redo снова отмечает правки. Восстановление сессии сохраняет эти состояния.
- Любая схема без файла требует подтверждения закрытия, включая серую. Это учитывается при одиночном и массовом закрытии вкладок, закрытии окна и удалении сессии. Массовое закрытие подтверждается один раз; отмена сохраняет вкладки.
- Для файлов жёлтый обозначает внешнее изменение, удаление или недоступность без локальных правок, красный — сочетание с локальными правками. Одно внешнее изменение не вызывает подтверждение закрытия вкладки. Сохранение и перезагрузка продолжают проверять конфликт на диске.
- Перед сохранением, дублированием, перезагрузкой и закрытием завершается ввод в поле свойств и считывается свежая модель. Полностью отменённые XML-правки не оставляют скрытого черновика и не блокируют последующее сохранение.
- Подсказки используют общий порядок сведений и формулировку «Схема не сохранена в файл». Убраны инструкции о будущем сохранении. Недоступность файла не описывается как изменение содержимого; описание индикатора совпадает с тултипом. Монитор обозначен как доступный только для чтения.

## Результаты

| Проверка | Результат |
| --- | --- |
| `npm run check` | TypeScript и ESLint прошли; 174 unit-теста в 36 файлах прошли |
| `npm run package:linux` | Linux x86_64 AppImage собран |
| `npm run test:e2e` | Полный итоговый прогон: 143 passed, 19 skipped, 0 failed; 6,4 минуты |
| Визуальная проверка Electron | Подсказки серого состояния в обеих темах и синего состояния в тёмной теме проверены |
| `git diff --check` | Прошёл |

Регрессионные сценарии воспроизводили синий дубликат с перенесённым XML-черновиком и блокировку сохранения после полной отмены XML-правок. Проверены дубликаты после правок свойств, неприменённого и применённого XML, независимые Undo/Redo, восстановление сессии и подтверждения закрытия. Нативные команды Electron учитывают фокус в поле; браузерный Ctrl+S сохраняет ещё не завершённый ввод. Проверки прежней доступной подписи индикатора обновлены под согласованные тексты.

Итоговый E2E-прогон включает Electron, извлечённый AppImage с sandbox, браузер и монитор с тестовыми REST-серверами. Условные сценарии Windows, внешнего Flowable и прежних интеграционных наборов пропущены. Код приложения после итоговой сборки не изменялся.

Артефакт: `release/BPMN-Desk-0.7.2-x86_64.AppImage`. Это локальная сборка, а не опубликованный файл 0.7.2. SHA-256: `e6b2fac24d3937b8be07f622f6c67268d6c83c5cc5ca3bb97726403e3b3c42b9`.

Windows и macOS в этом локальном прогоне не проверялись. Пуш и публикация не выполнялись.
