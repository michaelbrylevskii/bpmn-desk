# Проверка статусов схем без файла

Локальная доработка после 0.7.2, 12 ноября 2026 года. Правила: [ADR 0041](adr/0041-sessions-and-external-files.md).

## Поведение

- Новая схема, дубликат и локальная копия из монитора без правок показывают серую точку. Правки дают синюю; полная отмена возвращает серую.
- Любая схема без файла считается несохранённой работой: подтверждаются закрытие вкладки, закрытие окна и удаление содержащей её сессии. Восстановление сессии сохраняет это правило.
- Подсказка сообщает об отсутствии файла и выборе файла при сохранении. Отмена сохранения оставляет точку, сохранение в файл убирает её. Вкладки главной и монитора не получают этот маркер.
- Жёлтый и красный статусы локальных файлов сохраняются. Формат сессии не изменён; исходный снимок дубликата позволяет отличать правки от необходимости первого сохранения.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm run check` | TypeScript, ESLint; 172 unit-теста в 36 файлах прошли |
| `npm run package:linux` | Linux x86_64 AppImage собран |
| E2E | 138 сценариев подтверждены, 19 штатных пропусков; полный прогон и повторные проверки уточнённых тестовых сценариев |
| Финальные TypeScript, ESLint и `git diff --check` | Прошли |

Первоначальный полный E2E-прогон: 136 passed, 2 failed, 19 skipped. Потребовалось обновить подтверждение удаления сессии без файла и очистку после уже закрытого Electron. Каталог сессий перепроверен целиком; затем 5 сценариев AppImage и сводки прошли без ошибок. В AppImage устранена гонка обработки JavaScript-диалога между двумя CDP-клиентами; сами подтверждения проверяются отдельно в Chromium/Electron. Код приложения после сборки не изменялся.

Unit-проверки различают визуальные правки и необходимость сохранения, включая дубликат, восстановление, XML-черновик и сохранённый файл. E2E проверяет новую схему и дубликат, изменение и undo, отмену/подтверждение закрытия вкладок, копию из монитора, отмену закрытия окна, отмену сохранения и запись в файл. Обе темы и подсказка дополнительно проверены в Electron.

Артефакт: `release/BPMN-Desk-0.7.2-x86_64.AppImage`. Это локальная сборка с доработкой, а не опубликованный файл 0.7.2. SHA-256: `e63db9ac06512c923ec88c6949a1fa51905ad1d0fa877b6b9cceed043d1aef22`.

Windows и macOS в этом локальном прогоне не проверялись. Пуш и публикация не выполнялись.
