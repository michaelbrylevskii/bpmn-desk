# Критерии качества

Состав продукта — в [README](../README.ru.md). Архитектурные решения — в [ADR](adr/README.md).

| Область | Критерий |
| --- | --- |
| Данные | Неизвестные расширения сохраняются либо изменение явно блокируется; тихая потеря данных недопустима |
| Модель | Формы и холст изменяют BPMN только через command stack; документы имеют независимый undo |
| XML | Ошибка применения сохраняет действующую модель и черновик; полный импорт имеет явную границу истории |
| Файлы | Атомарное сохранение, проверка внешней ревизии, единый канонический путь открытия/сохранения |
| Сессии | Точный снимок вкладок и неприменённого XML, 15 последних сессий, повторная проверка файловых разрешений и состояния диска |
| Вкладки | Переходы сохраняют XML, undo, выбор и viewport; отмена открытия не теряет рабочий контекст |
| Монитор | Только чтение, точная версия определения, явная недоступность/неполнота, отсутствие N+1 |
| Сеть и секреты | Узкий IPC, ограничения HTTP, проверка TLS, защищённое хранение или память сессии |
| Интерфейс | Единые контролы, клавиатура, EN/RU, три темы, читаемые длинные значения |
| Материалы | Встроенные примеры имеют provenance и лицензию; пользовательские пакеты не публикуются |
| Код | Strict TypeScript без `any`, границы зависимостей, небольшие самостоятельные модули |
| Поставка | AppImage и Windows x64; платформенные заявления подтверждаются запуском на соответствующей ОС |

Основной набор самодостаточен: unit/roundtrip, UI/Electron, готовое приложение, независимый Flowable/H2 и официальные библиотеки моделей. Дополнительные пользовательские проверки не заменяют его. [Проверки и сборки](development.md) · [Результаты](validation.md).

## Ограничения файлов и экспорта

Локальный BPMN-файл ограничен 20 МБ. PNG — 16 384 px на сторону и 32 млн пикселей; для более крупных схем доступен SVG. Эти лимиты относятся к открытию файлов и экспорту изображения; ограничения запросов и выборок монитора описаны в [Flowable REST](runtime-monitor.md).

## Сессии и локальные файлы

Хранятся 15 последних сессий, включая несохранённые документы; самые старые удаляются при превышении лимита. Недавние файлы — отдельный список из 15 записей. Удаление недавнего файла не удаляет файл с диска. Сессии содержат содержимое схем, но не историю отмены и не ответы API монитора. Скрытие предложения восстановления сохраняется для выбранной сессии между запусками. Подробное поведение восстановления, конфликтов и меню — в [ADR 0041](adr/0041-sessions-and-external-files.md).
