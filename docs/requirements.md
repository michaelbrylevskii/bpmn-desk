# Требования

## Продукт и поставка

- BPMN Desk — просмотрщик и визуальный редактор BPMN 2.0, Flowable и Camunda 7; локальные файлы редактируются без сервера, авторизации и облака.
- Дополнительный монитор Flowable REST читает развёрнутые определения и запущенные экземпляры. Административные действия не предоставляются.
- Основная платформа — Linux x86_64, AppImage. Windows x64 — installer и portable; macOS пока не поставляется.
- Electron, React и строгий TypeScript. Небольшие модули с явной ответственностью, русская документация и ADR, отдельные коммиты завершённых изменений.
- Встроенные примеры — публичные лицензированные или оригинальные. Пользовательские схемы/provenance подключаются внешними локальными пакетами и не входят в Git, приложение или основной набор тестов.

## Редактор

- Создание BPMN 2.0 / Flowable / Camunda 7 с явным выбором профиля; определение открытого файла по URI namespace.
- Открытие, drag-and-drop, недавние файлы, CLI, независимые вкладки, сохранение и «Сохранить как».
- Визуальное изменение элементов и связей через bpmn-js; undo/redo, поиск, масштабирование, дерево элементов.
- Формы обоих движков, индикация явно заданных значений, дополнительные namespaced атрибуты и произвольные `extensionElements`.
- XML с поиском/заменой, переходом к выбранному элементу и подсветкой границ. Изменения применяются явно; ошибочный XML сохраняет действующую диаграмму.
- XML расширений выравнивается для чтения без изменения значимого текста, CDATA и вложенных отступов.
- Семантическое сохранение расширений: неподдерживаемые конструкции не теряются молча. Изменения модели проходят через command stack.
- Защита несохранённых изменений, recovery, атомарное сохранение и обнаружение внешнего изменения файла.
- Экспорт SVG и PNG с белым/прозрачным фоном; диагностика пересечений граничных событий и явная отменяемая команда размещения.

## Монитор

- Сохранённые профили серверов, none/Basic/Bearer, проверка формы до сохранения. Секреты — в защищённом хранилище ОС либо только в памяти сессии.
- Точная версия схемы экземпляра, positions active executions и dead-letter, счётчики multi-instance без изменения BPMN.
- Переменные процесса и выбранного execution, JSON, tasks, stacktrace по запросу; переходы к родителю и дочерним экземплярам.
- Каталоги определений, экземпляров и dead-letter: фильтры, сортировка и пагинация. Состояние экземпляра отображается в правой панели, без выборочно обновляющихся меток списка.
- Ограниченная сводка выбранной версии по явному запросу, без N+1 и полного обхода экземпляров; неполнота и отказ доступа явно обозначены.
- Несколько независимых мониторов рядом с документами, ручное и включаемое автообновление с сохранением холста. Неактивные мониторы не опрашивают сервер.
- Локальная копия развёрнутой схемы открывается в редакторе; SVG/PNG монитора содержит метки состояния, а BPMN — только схему.
- Ограниченные GET-операции выполняет Electron main; renderer не получает универсальный HTTP-доступ.
- Независимый Flowable 7.2/H2 с оригинальными схемами и настоящей ошибкой async executor используется для тестов; Java и стенд не входят в дистрибутив.

## Интерфейс

- Единая главная/стартовая страница: файл, создание схемы через меню профилей, монитор, примеры и недавние файлы. Кнопка «+» и Ctrl+N открывают обычную вкладку.
- Успешное открытие заменяет стартовую вкладку, отмена/ошибка сохраняют её. Соседние черновики, XML, undo и положение холста остаются доступны.
- Управление подключениями — общий инструмент приложения, выбор сервера и обновление — инструменты монитора.
- Английский по умолчанию, русский на выбор; переключение сохраняет модель и рабочий контекст.
- Системная, светлая и тёмная темы, единый акцент фокуса, современное оформление и собственные dropdown/listbox с клавиатурой.
- Масштаб интерфейса через Electron меню/клавиатуру; язык, тема и масштаб сохраняются. Системное меню вызывается Alt.
- Ошибки и успешные действия различаются визуально. Уведомления закрываются автоматически; наведение, фокус и подробности приостанавливают таймер, уход курсора имеет задержку.

## Границы и проверка

Редактор не исполняет expressions, scripts и Java delegates. Camunda 8/Zeebe, редактирование DMN/CMMN, внешние формы, совместная работа и облако не включены. Для визуального редактирования нужен BPMN DI; общей автоматической раскладки нет. Сериализация может менять форматирование, префиксы и CDATA при сохранении XML-семантики.

Монитор ориентирован на Flowable REST 7.2. Runtime Camunda 7, завершённые экземпляры и история, retry/deployment и OAuth/SSO не реализованы. Полнота снимка, ограничения переменных, таймаутов и сводки описаны в [runtime-monitor.md](runtime-monitor.md).

Обязательны strict TypeScript, ESLint, unit/roundtrip, UI/Electron, запуск AppImage, независимый runtime и официальные Java-проверки экспортов. Windows подтверждается отдельным запуском на Windows; ручная приёмка installer/portable и ассоциаций фиксируется отдельно. Актуальные результаты: [validation.md](validation.md). Решения: [ADR](adr/README.md).
