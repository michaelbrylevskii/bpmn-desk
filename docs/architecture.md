# Архитектура

## Границы модулей

| Область | Ответственность |
| --- | --- |
| `desktop` | Electron, окно/меню, IPC, файловые capabilities и настройки ОС |
| `desktop/runtime` | Профили, секреты, ограниченный HTTP, Flowable REST и декодирование |
| `shared` | Контракты, ошибки и каталоги переводов; без Electron/React/Node runtime |
| `renderer/platform` | Адаптеры preload и браузерного preview |
| `renderer/documents` | Жизненный цикл документов, локальные и внешние изменения, сохранение |
| `renderer/workspace` | Порядок/выбор вкладок, холст и панели документов |
| `renderer/bpmn` | bpmn-js, команды, XML, preservation, диагностика и экспорт |
| `renderer/engines`, `flowable`, `camunda` | Определение профиля по URI и специализированные формы расширений |
| `renderer/properties` | Формы выбранного элемента; изменение только через BPMN-адаптер |
| `renderer/runtime` | Каталоги, снимки, переменные/jobs и независимое состояние мониторов |
| `renderer/ui`, `styles`, `i18n` | Общие контролы, оформление и локализация |

Renderer не импортирует Node/Electron/desktop. Shared не зависит от UI. Strict TypeScript и `noUncheckedIndexedAccess` включены; ESLint проверяет границы и ограничивает исходные модули 280 содержательными строками.

## Документы и XML

Форма → BPMN-команда → command stack → сериализация → dirty/session → проверка → файловый IPC. Каждый документ имеет свой Modeler и историю; скрытые вкладки остаются смонтированными. Стартовая страница — тот же компонент в начальном состоянии и вкладке `home`; замена/закрытие вкладок вынесены в чистые функции.

Flowable/Camunda используют generic XML-узлы и `$attrs`, а не неполные moddle descriptors. Сравнение учитывает namespace URI, localName, атрибуты и текст. PreservationGuard сохраняет неизвестные данные при моделировании; невозможная без потерь сериализация блокируется. Copy/paste копирует расширения и обновляет известные глобальные ID.

Полный XML-черновик отделён от модели. Его применение начинает новую историю; ошибочный импорт сохраняет действующую модель. Правки свойств и XML расширений используют undo. Канонический путь и ревизия файла принадлежат main; атомарное сохранение обнаруживает внешние изменения.

## Runtime и безопасность

Монитор использует NavigatedViewer без команд моделирования. Метки состояния не меняют DI и BPMN. SVG-экспорт переносит overlays в графику; PNG строится из самодостаточного SVG. Локальная копия проходит обычный жизненный цикл документа без состояния исполнения.

Main предоставляет конкретные GET-операции, ограничения времени/размера, проверку TLS и запрет редиректов. Секреты находятся в памяти или защищённом хранилище ОС; renderer получает только признаки их наличия. Снимки и настройки подключений не входят в recovery документов. Неактивные мониторы не опрашиваются, устаревшие ответы игнорируются; сводка версии ограничена тремя параллельными запросами (executions, dead-letter и historic activities) с общим таймаутом подключения. Сводка начинает чтение после отображения выбранной схемы или XML fallback ([ADR 0038](adr/0038-diagram-priority-before-summary.md)). Общий переключатель сводки принадлежит приложению; контекст точной версии общий для каталогов экземпляров и заданий одного монитора. См. [ADR 0036](adr/0036-shared-definition-context.md) и [ADR 0037](adr/0037-global-summary-and-history.md).

Node integration выключен, IPC проверяет sender/frame, production UI использует собственный protocol и CSP. Скрипты, expressions и Java из схем не выполняются. Локальное редактирование не зависит от сети.

## Инструменты

Встроенные материалы ограничены `examples/` и сопровождаются provenance/лицензиями. Пользовательские пакеты и результаты находятся вне поставки; dev-сервер не отдаёт `.cache/` и `.local-schemas/`.

Независимый Flowable/H2, Java-валидаторы и адаптер CDP для готового приложения — только тестовые инструменты. Они не входят в ASAR. Команды и генерация скриншотов описаны в [development.md](development.md); детали решений — в [ADR](adr/README.md).

## Рабочие сессии и внешние изменения файлов

Main хранит снимки отдельно в `userData/sessions/`; индекс содержит закрепления и до 15 незакреплённых сессий. Запись атомарная, операции сериализуются. Имя и pin берутся из текущей записи main при автосохранении, чтобы запоздавший снимок не сбрасывал метаданные. Renderer передаёт только сериализуемое состояние и действующие файловые tokens; main проверяет привязку путей и исключает tokens из снимков. При восстановлении tokens выдаются заново для файлов сохранённой сессии. Прежнее recovery из localStorage однократно переносится в сессию; browser-preview использует localStorage и сохраняет его ограничения.

Документ хранит независимые основу файла, сериализацию модели и неприменённый XML. Статус файла определяется сравнением содержимого с основой, проверяется периодически и при возвращении окна в фокус. При сохранении main повторно проверяет ревизию; подтверждение перезаписи относится к конкретной версии файла. Перезагрузка использует проверяемый импорт редактора и сохраняет действующую модель при ошибке.

Сессия монитора содержит подключение, место просмотра, выбор и фильтры; ответы API и секреты не сериализуются. Восстановленный скрытый монитор монтируется при первом открытии и читает свежие данные. Правила интерфейса — [ADR 0041](adr/0041-sessions-and-external-files.md).

Окна имеют отдельные document capabilities и жизненный цикл сессии. Каналы IPC регистрируются один раз и выбирают обработчик по webContents отправителя; при закрытии окна его обработчики снимаются. Хранилища сессий, недавних файлов и подключений общие. Восстановление из занятого окна создаёт новое; команды приложения направляются в активное окно. См. [ADR 0042](adr/0042-session-windows.md).

## Проверка версий

Один сервис main читает публичный GitHub Releases API после открытия собранного приложения и каждые шесть часов. Все окна получают одинаковый статус через отдельный preload-контракт. Ошибки остаются незаметными; renderer показывает только доступность новой версии и запрашивает открытие фиксированной страницы релиза. Загрузка и установка остаются ручными. Ограничения запроса и правила сравнения — [ADR 0044](adr/0044-release-checks.md).
