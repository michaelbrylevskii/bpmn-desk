# 0016. Отступы отдельного XML-блока расширений

Статус: принято. Дата: 2026-10-09.

## Контекст

При извлечении extensionElements из полного документа сериализатор теряет отступ перед корнем, но сохраняет исходные пробелы внутри. В панели справа первая строка начинается слева, а остальные сдвинуты отступами definitions/process/task.

## Решение

Адаптер `bpmn/xml-fragment-format` форматирует копию DOM-фрагмента перед показом. Корневой тег начинается с левого края, вложенные элементы получают два пробела на уровень. Комментарии и processing instructions остаются на своих местах. Открытие панели не меняет модель; применение идёт через прежнюю отменяемую команду.

Отступы меняются только в контейнерах с дочерними элементами и без значимого текста. Текстовые значения, CDATA, mixed content и поддеревья с `xml:space="preserve"` сохраняются. Namespace и атрибуты сериализует существующий XMLSerializer. Новая зависимость не нужна.

## Альтернативы и последствия

Удаление общего числа пробелов из всех строк повредило бы многострочные scripts и строки. Форматирование всего XML не требуется для этой панели и затронуло бы пользовательский черновик. В блоках со значимыми пробелами остаётся исходное оформление; сохранность данных важнее одинаковых отступов внутри таких значений.

Проверки сравнивают семантику дерева, исходные текстовые узлы и неизменность входного DOM, а также применение фрагмента с другим namespace prefix.
