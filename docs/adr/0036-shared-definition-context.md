# 0036 — Общий контекст точной версии определения

Статус: принято. Дата: 2026-10-30. Заменяет правило независимых копий предфильтра из [ADR 0035](0035-monitor-filter-tabs-and-panel-scroll.md).

## Решение

Переход «Экземпляры» задаёт один контекст точного `processDefinitionId` для Runtime, History и Dead-letter jobs текущего монитора. Контекст хранится отдельно от локальных условий вкладок и добавляется к запросу выбранного каталога. Definitions он не ограничивает. Другой монитор и другое подключение имеют собственный контекст.

Чип контекста выделен фиолетовым оттенком и значком связи; подсказка содержит точный ID и область действия. Удаление чипа из любой из трёх вкладок снимает контекст везде. «Сбросить фильтры» очищает общий контекст и локальные условия текущей вкладки; локальные условия других вкладок сохраняются. Страницы всех затронутых каталогов возвращаются к первой. Изменение ID через форму при установленном контексте изменяет общий контекст.

## Последствия и проверка

Нет скрытых трёх копий одного ограничения. Обычные фильтры сохраняют независимость, семантику AND и прежнее оформление. Контекст не сохраняется между запусками. Unit-тест проверяет независимость условий и сброс страниц, Electron — общий чип, удаление и запросы всех каталогов. Новых зависимостей и серверных запросов нет.
