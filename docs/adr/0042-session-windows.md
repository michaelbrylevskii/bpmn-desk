# 0042 — Отдельное окно для восстановления сессии

Статус: принято и реализовано локально. Дата: 2026-11-08.

Уточняет [0041](0041-sessions-and-external-files.md): восстановление не смешивает рабочие наборы.

## Решение

Если в текущем окне только стартовые страницы, сессия восстанавливается в нём. Если открыта хотя бы одна схема или монитор, восстановление открывает отдельное окно; исходные вкладки, несохранённая работа и выбор остаются нетронутыми. Если сессия уже открыта в другом окне, оно показывается и получает фокус вместо создания копии.

Каждое окно сохраняет собственную сессию и закрывается независимо. Снимки, 15 недавних сессий и 15 недавних файлов хранятся в общем профиле приложения. Открытая в другом окне сессия доступна для перехода к окну; удаление её снимка недоступно до закрытия окна. Сессии открытых окон не предлагаются как требующие восстановления.

Main маршрутизирует IPC по отправителю и основному frame. Файловые capabilities принадлежат одному окну и не принимаются другим. Подключения и их секреты обслуживаются общим хранилищем main; настройки языка, темы и переключателя сводки согласуются между окнами. Изменения подключений и списков передаются другим окнам без пересоздания схем. Меню приложения и команды относятся к окну в фокусе. Файл, открытый повторным запуском приложения, передаётся последнему активному окну.

Один файл можно открыть в нескольких окнах. Сохранение в одном обнаруживается другим как изменение на диске; локальная работа не заменяется. Undo каждого документа изолирован. Буфер фигур остаётся общим только для вкладок одного окна; перенос фигур между окнами не входит в эту итерацию.

## Последствия и проверка

Нужны проверки восстановления из пустого и занятого окна, фокусировки уже открытой сессии, независимого закрытия, команд меню и файловых разрешений, общих подключений/списков/предпочтений и конфликтов общего файла. Старые черновики мигрируются один раз в общий список сессий. Browser-preview воспроизводит восстановление занятой сессии в отдельной вкладке браузера; нативные проверки выполняются через Electron.
