# 0008. Языки интерфейса и компактный поиск XML

Статус: принято. Дата: 2026-10-08. Уточняет [ADR 0007](0007-interface-and-navigation.md) в части панели поиска и визуальной индикации свойств.

## Контекст

После проверки 0.1.1 пользователь попросил уменьшить визуальный шум: выровнять поиск XML, сделать панель компактнее, убрать подписи состояния полей и поясняющий абзац. Дополнительно согласованы английский язык по умолчанию и выбор английского/русского через меню.

## Решение

Поиск получает отдельный `XmlSearchPanel`, реализующий публичный контракт панели CodeMirror. Используются штатные `SearchQuery`, `findNext/findPrevious`, замена и выделение совпадений; собственный движок поиска не вводится. Одна строка содержит поле, навигацию, счётчик, режимы регистра/regex/целых слов и раскрытие замены. Строка замены изначально скрыта. Все контролы имеют высоту 30px, текст полей — 12px; при недостатке ширины элементы переносятся. Названия действий доступны в aria-label и подсказках, выбранные режимы — в aria-pressed. Неверный regex отмечается, подсчёт ограничен 10 000 совпадений, поиск/переходы продолжают работать по документу.

В свойствах сохраняются `data-presence` и акцентная боковая грань собственных значений, включая false/0. Подписи «Задано / По умолчанию / Не задано» рядом с названиями и поясняющий абзац удаляются. Значения и действия сброса в select остаются функциональными контролами.

Языки — `en` и `ru`, default — `en`, независимо от локали ОС. В desktop источник истины — `language.json` в профиле Electron. Значение валидируется, записывается атомарно и применяется только после успешной записи; при отсутствии/повреждении используется en. IPC проверяет отправителя и значение. Выбор доступен в native меню `Language / Язык` и компактном переключателе EN/RU в toolbar. Browser preview использует localStorage через тот же контракт bridge.

Типизированные каталоги разделены на интерфейс, свойства и уведомления в `src/shared/i18n`. Существующие русские тексты являются стабильными ключами, английские значения задают default. Это позволяет сохранить исходные диагностические сообщения и мигрировать интерфейс без массовой замены идентификаторов. Параметры подставляются отдельно от текста. Для существующих сообщений и IPC ошибок предусмотрен адаптер точных текстов/шаблонов; более конкретные шаблоны имеют приоритет. Неизвестные технические сообщения сторонних библиотек сохраняются исходными. Новых runtime зависимостей нет.

React LanguageProvider обновляет текст без пересоздания документов. CodeMirror Compartment меняет phrases/aria-label, сохраняя query, раскрытие замены, выделение и undo. bpmn-js получает функцию текущего языка и публичное событие `i18n.changed`; контекстная панель обновляется без команд модели. Native меню перестраивается отдельно от жизненного цикла окна и обработчиков масштаба, поэтому горячие клавиши не дублируются.

Имена/ID элементов, XML, Flowable expressions, пользовательские значения и имена существующих файлов не переводятся. Только создание новой схемы/определения использует локализованные начальные подписи. Восстановленные/открытые документы сохраняют свои данные. Документация и ADR остаются русскими.

## Альтернативы

- Только CSS поверх стандартной панели поиска: не позволяет удобно скрывать замену и сократить подписи режимов.
- Автоматически выбирать язык ОС: отклонено, пользователь явно выбрал английский default.
- Перезагружать окно для смены языка: отклонено из-за потери фокуса, черновиков и истории.
- Подключать i18next для двух локалей: текущим каталогам и параметрам достаточно небольшого типизированного адаптера.

## Проверка и последствия

E2E проверяют геометрию контролов поиска, замену с undo, обе локали, смену языка с XML-черновиком и сохранением истории, локализацию уведомлений, native меню/перезапуск и отсутствие дублирования zoom. Для пяти реальных схем выполняется переключение en/ru перед экспортом, сохраняются расширения и исполняемая модель Flowable. Подписи состояния не возвращаются в UI; семантика определения заданных значений из ADR 0007 сохраняется.

Редкие термины bpmn-js, ещё отсутствующие в русском словаре, остаются английскими. XML и интерфейс имеют независимые языки. Новая локаль потребует каталога, phrases CodeMirror, словаря bpmn-js и выбора в меню; язык не является частью BPMN-файла.
