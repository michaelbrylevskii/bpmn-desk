# 0004. Команды атрибутов и Flowable DI

Статус: принято. Дата: 2026-10-08.

## Контекст

UI E2E показал, что `$attrs` moddle доступен через getter: `set('$attrs', ...)` создаёт лишний XML-атрибут, присваивание словаря запрещено. Добавление namespace и атрибута должно отменяться одним undo. В схеме с развёрнутым подпроцессом отсутствует isExpanded, хотя DI дочерних элементов лежит на той же plane.

## Решение

Собственная команда заменяет содержимое `$attrs`, хранит копии прежних значений и атомарно меняет namespace и атрибут. Для импорта восстанавливаем отсутствующий isExpanded только при наличии DI потомков на той же plane. Явные значения флага не меняем. Оригинальные файлы не переписываем.

## Последствия

Формы и кастомные атрибуты имеют единый undo/redo. Сохранённая копия Flowable XML может получить стандартный DI-флаг развёрнутого подпроцесса. На XML-импорте нормализация повторяется идемпотентно.
