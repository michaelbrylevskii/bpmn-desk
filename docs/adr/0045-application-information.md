# 0045 — Окно «О приложении»

Статус: принято. Дата: 2026-11-10.

Логотип в шапке редактора и монитора — кнопка открытия компактного модального окна «О приложении». В нём показаны BPMN Desk, версия сборки, назначение приложения, автор **Mikhail Brylevskii**, подпись о совместной работе с OpenAI Codex и ссылка на репозиторий GitHub. Имя автора пишется как Mikhail; `michaelbrylevskii` сохраняется в логинах и URL.

Техническая информация включает платформу и архитектуру, работающие версии Electron, Chromium и Node.js, лицензию кода MIT. Версии возвращает main через отдельный `window.application`; renderer не читает Node или файловую систему. Номер сборки берётся из `app.getVersion()`, независимо от временной dev-версии индикатора обновлений. Browser-preview показывает доступные сведения о продукте без вымышленных версий Electron.

Ссылка автора открывает `https://github.com/michaelbrylevskii`, ссылка проекта — `https://github.com/michaelbrylevskii/bpmn-desk`. Main принимает только идентификаторы `author` и `repository`, выбирает фиксированный HTTPS-адрес и открывает системный браузер; renderer не передаёт произвольные URL. Вызовы ограничены главным frame зарегистрированного окна. Открытие диалога не обращается к сети; ошибка явного открытия ссылки показывается внутри диалога.

Используется нативный HTML dialog с фокусом внутри окна. Закрытие крестиком или Escape возвращает фокус логотипу; состояние документов, выбранная схема и навигация монитора не меняются. Диалог поддерживает обе темы и локали. Проверяются сведения, ссылки, закрытие и восстановление фокуса, настоящий desktop IPC и отклонение неизвестного идентификатора ссылки.
