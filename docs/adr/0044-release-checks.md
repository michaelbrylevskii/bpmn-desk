# 0044 — Фоновая проверка версий

Статус: принято. Дата: 2026-11-10.

## Поведение

Собранное приложение проверяет последний стабильный релиз GitHub после загрузки первого окна и затем каждые шесть часов, пока приложение открыто. Проверка не задерживает интерфейс, открытие схем или работу монитора. Новые окна используют общее состояние и не запускают дополнительные запросы.

Если версия релиза новее установленной, существующий бейдж версии получает оранжевое оформление. Текст бейджа остаётся номером установленной версии; доступная версия и действие указаны в обычной подсказке приложения, доступной также с клавиатуры. Нажатие открывает страницу последнего релиза в системном браузере. Серый бейдж не интерактивен.

Сетевая ошибка, HTTP-ошибка, таймаут или некорректный ответ возвращают обычное серое оформление, включая случай, когда предыдущая проверка нашла обновление. Уведомления, индикатор загрузки и немедленные повторы не показываются. Состояние между запусками не сохраняется. Автоматической загрузки, установки и перезапуска нет; механизм одинаков для AppImage, Windows installer и portable.

## Границы и реализация

Отдельный сервис `src/desktop/updates` принадлежит main-процессу. Он выполняет публичный GET к фиксированному `https://api.github.com/repos/michaelbrylevskii/bpmn-desk/releases/latest` без авторизации и cookies. Настройки подключений к движкам, секреты и содержимое документов в запрос не включаются. Таймаут десять секунд охватывает заголовки и тело ответа; предел тела — 256 КиБ. Redirect запрещён. Учитываются только корректные стабильные теги `vMAJOR.MINOR.PATCH` или `MAJOR.MINOR.PATCH`, строго новее установленной версии; draft и prerelease отвергаются. Сравнение числовое, а не строковое.

Контракты статуса, подписки и открытия релиза находятся в `src/shared/updates.ts`; preload предоставляет отдельный `window.updates`. Renderer не выполняет сетевые запросы и не задаёт внешние URL. Main открывает только фиксированную HTTPS-страницу релизов текущего репозитория, если обновление доступно. IPC принимает вызовы только из главного frame зарегистрированного окна. Подписки удаляются при закрытии окон, запрос и периодический таймер прекращаются при завершении приложения.

В режиме разработки и browser-preview публичная проверка отключена; сервис и UI проверяются изолированными ответами. Дополнительные зависимости и настройки не требуются. Семантика endpoint описана в [GitHub REST API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release).

## Проверка

Unit-тесты проверяют выбор версий, периодичность, общее состояние, таймауты заголовков и тела, ограничения ответа, ошибки и восстановление после них. UI-тесты проверяют подсказку, обе темы, клавиатуру, открытие релиза, возврат к серому оформлению и согласование начального snapshot с событиями. Итоговые команды и результаты фиксируются в [протоколе](../validation-updates.md).
