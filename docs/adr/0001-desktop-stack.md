# 0001. Desktop и стек

Статус: принято. Дата: 2026-10-08.

## Контекст

Нужен автономный локальный редактор с одинаковым поведением на Linux и Windows. Требуется поддерживаемая кодовая база и AppImage.

## Решение

Electron + React + strict TypeScript. Vite собирает renderer, electron-vite — main/preload. electron-builder формирует AppImage и Windows installer. В renderer выключен Node.js, включены sandbox и contextIsolation. Узкий preload API предоставляет только операции с документами.

## Альтернативы

Tauri уменьшает размер дистрибутива, но добавляет Rust и различия системных WebView. Веб-приложение усложняет обычное сохранение локальных файлов. Собственный нативный холст потребовал бы реализации BPMN-моделера.

## Последствия

Больший размер приложения в обмен на единый Chromium и TypeScript. Сборки и системная интеграция проверяются на каждой ОС отдельно. Основная разработка и проверка — Linux.
