# 0041 — Рабочие сессии, состояние файлов и меню

Статус: принято; реализация в работе. Дата: 2026-11-08.

Дополняет [0005](0005-files-and-recovery.md), [0011](0011-recovery-and-hidden-tabs.md), [0021](0021-workspace-tabs-and-runtime-export.md), [0028](0028-tab-reordering.md). Заменяет правила восстановления только черновиков, отсутствия сохранения порядка и мониторных вкладок между запусками.

## Сессии

Сессия — рабочий набор вкладок, а не история действий и не резервное копирование без срока хранения. Состояние сохраняется по ходу работы и перед закрытием приложения. Пустой запуск не создаёт запись. Сохраняются порядок вкладок и активная вкладка; при переключении вкладок модели и независимые истории отмены остаются в памяти.

Для локальных схем сохраняются точное содержимое модели, неприменённый XML, исходный путь, основа для определения локальных и внешних изменений, масштаб, положение холста и выбор элемента. Даже чистая сохранённая схема восстанавливается из снимка сессии, а не заменяется актуальным файлом с диска. История отмены между запусками не переносится. Отброшенные явно при закрытии вкладки изменения не должны возвращаться через предыдущий снимок той же сессии.

Файловые разрешения и tokens из прежнего процесса не переносятся: main заново связывает сохранённый путь с документом. После восстановления выполняется та же проверка диска, что и при работе с уже открытым документом. Если файл изменился, чистая вкладка получает жёлтый статус, изменённая — красный. Если файл исчез, содержимое снимка остаётся доступным.

Монитор восстанавливает подключение, место просмотра, выбранный раздел и фильтры. Секреты подключения и ответы API не входят в снимок сессии; данные читаются заново. Фоновые мониторы не должны запускать массовую загрузку до открытия. Недоступное или удалённое подключение отображается явно, без подмены другим.

Новая работа после игнорирования предыдущей сессии сохраняется отдельно. Восстановленная сессия становится текущей и обновляется без создания одинаковых записей. Если рабочее пространство уже содержит вкладки, восстановление добавляет вкладки, не закрывает существующие и не заменяет их несохранённое содержимое. Уже открытые файлы не дублируются.

Хранятся последние **15 сессий независимо от наличия несохранённых изменений**. При превышении лимита самые старые удаляются вместе со снимками. Последние **15 недавних файлов** хранятся отдельно. Ошибки сохранения состояния показываются пользователю.

## Главная страница и предложение восстановления

Имеющаяся плашка восстановления предлагает восстановить последнюю подходящую сессию. Она показывает краткую числовую сводку, кнопку восстановления и крестик.

Крестик скрывает предложение **для конкретной сессии с сохранением между перезапусками**. Запись остаётся в списке сессий. Другая подходящая сессия может быть предложена независимо. После восстановления скрытой сессии признак скрытия снимается: после последующей работы её снова можно предложить. Простое обновление даты не сбрасывает скрытие.

На главной два отдельных списка: **«Недавние сессии»** вместо списка примеров и **«Недавние файлы»**. Строки оформлены схоже и компактно. У сессии дата и краткая числовая сводка находятся в одной строке; наличие несохранённых документов отмечено акцентом. Детали и все вкладки доступны в кастомном тултипе. На каждой строке есть крестик: у сессии он удаляет запись и снимки (при несохранённой работе — с подтверждением), у файла — только запись недавнего, без удаления файла с диска.

Верхние действия: «Открыть файл», **«Создать схему ▾»**, **«Открыть монитор ▾»**. Меню монитора содержит подключения и пункт «Новое подключение…»; отдельного большого блока монитора нет. Примеры сохраняются в конце меню создания: разделитель и **«Примеры схем ▸»**. Когда оба списка пусты, доступна неброская ссылка на тот же список примеров. При обычной работе примеры не занимают акцентное место.

## Состояние локального файла

| Локальные изменения | Состояние диска | Маркер |
| --- | --- | --- |
| Нет | Соответствует исходной версии | Нет |
| Есть | Соответствует исходной версии | Синий |
| Нет | Изменён или удалён | Жёлтый |
| Есть | Изменён или удалён | Красный |

Тултип при наведении на вкладку содержит имя, полный путь и прикладное объяснение локального и внешнего состояния. Цвет не является единственным источником информации. Недоступность для чтения отличается от удаления в тексте и доступных действиях.

Изменения обнаруживаются во время работы и при возвращении в приложение. Собственное сохранение и запись идентичного содержимого не создают ложный конфликт. Файлы не перезагружаются автоматически. Для активного документа доступно компактное сообщение об изменении с действием перезагрузки.

Перезагрузка читает файл заново; при локальных изменениях требуется подтверждение их потери. Неприменённый XML также считается локальной работой. Некорректный внешний XML не заменяет текущую модель. Масштаб, положение и выбор по возможности сохраняются; история отмены сбрасывается.

При сохранении в исходный изменившийся файл диалог предлагает **«Отмена» / «Сохранить как…» / «Перезаписать файл»**. Для удалённого — **«Отмена» / «Сохранить как…» / «Создать файл заново»**. При недоступности для чтения показывается причина и доступны отмена и сохранение копии. Перезапись не является действием по умолчанию; состояние проверяется заново перед записью.

## Меню

Контекстное меню вкладки объединяет применимые к её типу действия:

- Сохранить; Сохранить как…
- Дублировать схему.
- Перезагрузить с диска.
- Показать файл в папке — системный файловый менеджер с выделением файла.
- После разделителя: Закрыть; Закрыть другие вкладки; Закрыть все вкладки.

Дубликат содержит текущее состояние схемы, включая несохранённую работу и неприменённый XML, и не связан с исходным файлом. История отмены независима. Массовое закрытие использует общее подтверждение по изменённым документам, без цепочки отдельных окон.

Меню приложения по Alt пересматривается вместе с командами: файлы и экспорт, вкладки, подключения, навигация монитора, вид. Доступность соответствует активному контексту. Правка учитывает фокус текстового поля, XML-редактора и холста. Команды меню, тулбара и горячих клавиш вызывают одно поведение.

## Проверка и границы реализации

Нужны проверки повторного запуска, скрытия плашки, хранения и удаления 15 записей, точного снимка чистой/изменённой схемы, неприменённого XML, порядка и выбранной вкладки, добавления к открытому пространству, отсутствующих файлов/подключений, свежих данных монитора и отложенной загрузки скрытых мониторов. Для файлов проверить изменение/удаление/недоступность, возврат к исходному содержимому, собственное сохранение, повреждённый XML, подтверждения перезагрузки и конфликта, повторную проверку перед записью. Проверить меню мышью и клавиатурой, обе локализации и темы.

Техническое размещение снимков, формат миграции существующих recovery-записей и способ наблюдения за файлами выбираются при реализации с сохранением этих правил. Снимки и пользовательские файлы не входят в Git или дистрибутив. Реализация локальная, каждый завершённый блок — отдельный коммит; пуш и выпуск требуют отдельного запроса. Перед сдачей: npm run check, npm run test:e2e, npm run package:linux. Проверенными объявляются только фактически запущенные платформы.
