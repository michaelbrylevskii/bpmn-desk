# 0027 — Буфер элементов между схемами

## Контекст

Каждая вкладка содержит отдельный bpmn-js Modeler и историю команд. Его локальный clipboard не позволяет вставить выделение в другую вкладку.

## Решение

App создаёт один DiagramClipboard на окно и передаёт его редакторам через DI bpmn-js. Copy/paste, выделение, связи, вложенные элементы, генерация ID и undo/redo остаются штатными командами принимающего редактора. Адаптер копирования сохраняет generic XML и объявления пространств имён атрибутов, унаследованные от исходного документа.

## Альтернативы

Сериализация выделения в системный буфер потребовала бы собственного формата, обработки IPC и восстановления модели. Для переноса между открытыми вкладками это избыточно.

## Последствия

Буфер живёт до закрытия окна и доступен после закрытия вкладки-источника. Между окнами, экземплярами приложения и внешними редакторами перенос через системный буфер не поддержан. Ссылки на внешние процессы, классы, формы и ресурсы сохраняются как значения; соответствующие ресурсы автоматически не переносятся. Перенос свойств не конвертирует модель между движками.
