# 0033 — Единые каталоги, поиск и терминология монитора

Статус: принято. Дата: 2026-10-30.

## Решение

Каталог развёрнутых определений называется `Definitions / Определения`; запуск — `Instance / Экземпляр`. ID, ключ, имя и версия определения различаются. «Схема» обозначает визуальное представление, а не экземпляр в движке.

Все каталоги используют одну форму: критерий, поле, поиск/обновление, затем применённые условия и дополнительные фильтры. Поле ID экземпляра открывает известный экземпляр без подмены поиска списка; отдельной формы для этого нет. Поиск выполняется на сервере до пагинации. Условия определений, текущих/завершённых/всех исторических экземпляров и заданий сохраняются отдельно на время жизни монитора. Они не сохраняются на диск.

По имени определения используется `nameLike`, по ключу — точное совпадение. Для текущих и исторических экземпляров доступны точный business key, частичный business key без учёта регистра и частичное имя экземпляра без учёта регистра. `%` и `_` сохраняют смысл шаблонов Flowable; это видно рядом с поиском. Для заданий доступны ID экземпляра, execution и элемента. Дополнительные условия применяются через AND.

Различие REST-параметров текущих и исторических имён скрыто в desktop-адаптере: `nameLikeIgnoreCase` и `processInstanceNameLikeIgnoreCase`. Источники: [runtime GET](https://github.com/flowable/flowable-engine/blob/flowable-7.2.0/modules/flowable-rest/src/main/java/org/flowable/rest/service/api/runtime/process/ProcessInstanceCollectionResource.java), [history GET](https://github.com/flowable/flowable-engine/blob/flowable-7.2.0/modules/flowable-rest/src/main/java/org/flowable/rest/service/api/history/HistoricProcessInstanceCollectionResource.java). HTTP-адаптер остаётся GET-only; объединения страниц нескольких поисковых запросов нет.

Последние версии включены по умолчанию и при сбросе условий. Явный выбор всех версий сохраняется при переключении каталогов. Это заменяет соответствующее значение по умолчанию в ADR 0022. Схема экземпляра и контекстная ссылка всегда используют его точный `processDefinitionId`, включая старую версию.

Строка каталога имеет одно основное действие, название, контекст и ID. Переход к экземплярам выбранной версии находится после имени/версии в заголовке схемы. Из экземпляра в том же месте доступно его определение. Выбор элемента, фильтр журнала и раскрытие каждой исторической записи независимы; программный фокус не включает фильтрацию.

## Альтернативы

Поиск сразу по нескольким полям с объединением отдельных запросов не вводится: без серверного OR невозможно сохранить обычную серверную пагинацию, сортировку и точный total простым объединением текущих страниц. Автоопределение ID по форме строки отклонено, чтобы не путать его с бизнес-ключом.
