# 0025 — Продуктовая документация и языки публикации

Статус: принято. Дата: 2026-10-11.

## Решение

README.md — компактная английская страница продукта, README.ru.md — эквивалентный русский перевод. Возможности, поддержка, загрузка и границы описываются без пошаговой инструкции по очевидным действиям интерфейса. Проектная документация остаётся русской и имеет общий индекс; команды разработки собраны в одном документе, предыдущие протоколы проверок перенесены в архив. ADR сохраняют решения, включая заменённые.

Обложка снимается с двух живых UI одинаковой геометрии в разных темах. HTML-таблица содержит кликабельные миниатюры; пользовательские материалы не используются. Скрипт захвата воспроизводит изображения без bitmap-редактирования.

Английский текст GitHub release notes хранится в `.github/release-notes/`, русский — в `docs/releases/`. Генератор соединяет их с `<details>` для русского; CI и обновление существующих релизов используют один генератор. Он не меняет теги и дистрибутивы.

## Проверка

Рендеринг проверяется через GitHub Markdown API, изображения — визуально. Проверяются относительные ссылки, паритет README, два языка notes, закрытый спойлер и соответствие manifest. Зависимости приложения и поведение редактора не изменяются.

Проверено на Linux: `check` (86 unit-тестов), `test:e2e` (65 успешных проверок), `package:linux` и runtime-сценарий съёмки монитора. GitHub Markdown API сохранил HTML-таблицу и закрытый `<details>`; на реальной странице GitHub проверены две README и мобильная ширина. Обновлённые тексты трёх опубликованных релизов совпадают с генератором; идентификаторы и digests артефактов сохранены. Новые Windows/macOS прогоны не выполнялись.
