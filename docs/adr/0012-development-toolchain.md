# 0012. Контракт среды разработки и запуск Maven

Статус: принято. Дата: 2026-10-09.

## Контекст

Указание «Node.js 22.12+» включало версии, которые не поддерживает установленный Vitest. На Windows Maven запускается через `mvn.cmd`; прямой вызов такого файла через Node spawn без обработки командной оболочки не работает.

## Решение

Поле `engines.node` повторяет диапазон установленного Vitest: `^22.12.0 || ^24.0.0 || >=26.0.0`. Для разработки рекомендуется Node.js 24; результат текущего прогона на Node.js 26 отражён в отчёте проверки.

Скрипт независимой проверки Flowable использует `cross-spawn@7.0.6` для запуска Maven и Java. Библиотека обрабатывает Windows `.cmd`, поиск исполняемого файла и экранирование аргументов, в том числе путей с пробелами. Она уже присутствовала транзитивно; теперь объявлена прямой devDependency, поскольку скрипт обращается к ней напрямую. В приложение зависимость не включается.

## Альтернативы

Ручное составление команды `cmd.exe` требует поддержки правил экранирования Windows. Откат инструментов ради более широкого диапазона Node.js не нужен для выбранного стека.

## Последствия

Отсутствие Maven или Java сообщает об ошибке запуска с подсказкой по установке. Успешный Linux-прогон проверяет существующий путь исполнения; работоспособность на Windows требует отдельного нативного прогона.
