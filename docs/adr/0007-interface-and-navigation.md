# 0007. Масштаб интерфейса, тема холста и навигация по XML

Статус: принято. Дата: 2026-10-08. Панель поиска и текстовые подписи индикации уточнены в [ADR 0008](0008-languages-and-compact-search.md).

## Контекст

После ручной проверки понадобились масштаб всего интерфейса, согласованная тёмная тема диаграммы, поиск по XML, переход от выбранного элемента к исходнику и различение заданных свойств и умолчаний. Граничные события могут закрывать маркер вызова процесса. Регрессионный пример `boundary-events` воспроизводит перекрытие на элементе `reviewCall`.

## Решение

Масштаб интерфейса меняется через native меню Electron «Вид» и Ctrl+/Ctrl−/Ctrl0; поддерживаются Ctrl= и macOS-эквивалент Cmd. Диапазон — 50–175%, шаг — 10 процентных пунктов. Значение хранится в профиле Electron, записывается атомарно и восстанавливается при загрузке окна. Масштаб BPMN viewport независим; вписывание схемы назначено на CtrlShift0. ResizeObserver уведомляет canvas при изменении размеров контейнера.

Тема диаграммы задаётся CSS-переменными цветов renderer bpmn-js. DI-цвета исходной схемы имеют приоритет; для явно заданной заливки без цвета подписи выбирается контрастный текст в DOM. Тема не изменяет модель, историю команд и dirty state. SVG экспортируется в самодостаточной светлой палитре: переменные заменяются конкретными цветами, явные цвета DI сохраняются. Внутренний DOCTYPE штатного SVG bpmn-js удаляется перед безопасным XML-разбором; внешние сущности не загружаются.

Поиск использует официальный `@codemirror/search`: CtrlF, кнопка, переходы между совпадениями, регистр, слова, regex и замена. `@lezer/xml` используется как явная зависимость для поиска элемента по `id` в синтаксическом дереве. Это исключает ложные совпадения в комментариях/CDATA и учитывает вложенные и самозакрывающиеся теги. CodeMirror StateField подсвечивает диапазон элемента и отдельно его открывающий/закрывающий теги. Выбор на холсте прокручивает XML без изменения текста и захвата фокуса; есть повторный переход кнопкой. Смена темы через Compartment сохраняет поиск и undo XML.

Состояние поля — «Задано», «По умолчанию», «Не задано». Для стандартных свойств учитывается собственное значение moddle-объекта и descriptor default; для Flowable/кастомных атрибутов — наличие ключа. Явные false и 0 считаются заданными. Умолчания движка Flowable не выводятся из предположений. Поведение стандартного undo bpmn-js дополняется восстановлением отсутствующего свойства: штатный revert иначе превращает prototype default в собственное значение.

Диагностика проверяет пересечения граничных событий друг с другом и маркером свёрнутого подпроцесса/вызова процесса. Команда «Разнести события» доступна в свойствах и диагностике. План выбирает ближайшие к исходным координатам свободные точки на границе host с зазором, учитывает другие фигуры и маркер; при нехватке места операция отклоняется до изменения модели. Перемещения выполняются вложенными штатными командами bpmn-js: привязки событий сохраняются, связи перестраиваются, весь набор отменяется одной командой. Импорт не исправляет координаты автоматически.

Основные инструменты bpmn-js переведены через штатный сервис translate. Для редких неподдержанных словарём терминов сохраняется оригинал. Стартовый экран описывает операции с файлами; технические имена BPMN/Flowable остаются доступны в формах.

## Альтернативы

- `webFrame` в renderer для масштаба: отклонено, native меню и настройки относятся к desktop-слою.
- Перезапись DI-цветов при смене темы: отклонена из-за изменения файлов при настройке отображения.
- Поиск тегов regex: отклонён, не учитывает вложенность и комментарии.
- Автоматическое перемещение событий на импорте: отклонено, изменяло бы исходную геометрию без явного действия.
- Полная автоматическая раскладка процесса: выходит за рамки локального исправления найденного перекрытия.

## Последствия

Светлая/тёмная тема отображения и масштаб UI не являются частью BPMN-файла. XML-навигация работает по актуальному черновику; отсутствующий ID отмечается, незавершённый тег не подсвечивается. Форматирование XML и канонические правила moddle сохраняются: явно заданное стандартное значение, равное descriptor default, может быть опущено при экспорте и после переоткрытия отображаться как умолчание; исполняемая семантика остаётся той же.

Исправление граничных событий меняет DI и маршруты связей после явной команды и обычного сохранения. Оно не является общей раскладкой и не исправляет все возможные пересечения линий и подписей. Проверки включают тему/DI/SVG, XML-навигацию и поиск, сохранение XML undo при смене темы, статус false после undo, native масштаб с восстановлением и отмену размещения реальной схемы. Совместимость исполняемой модели проверяется конвертером Flowable.
