# 0035 — Вкладки источников, фильтры и прокрутка подробностей монитора

Статус: принято. Дата: 2026-10-30. Уточняет [ADR 0033](0033-monitor-catalog-search.md) и [ADR 0034](0034-automatic-summary-status.md) по обратной связи после локальной проверки.

Уточнение следующей итерации: [ADR 0036](0036-shared-definition-context.md) заменяет копии контекста; [ADR 0037](0037-global-summary-and-history.md) заменяет настройку и бюджет сводки, добавляет history и постоянную панель.

## Решение

Каталог имеет четыре вкладки: `Definitions / Определения`, `Runtime / Текущее состояние`, `History / История`, `Dead-letter jobs`. Вкладки Runtime и History отражают источник API, а не статус завершения: history содержит и продолжающиеся процессы. Фильтр состояния history позволяет выбрать завершённые записи или записи без окончания. Одна схема по-прежнему совмещает оба источника. Выбор строки runtime/history открывает соответствующую правую вкладку; переключение справа остаётся доступным вручную.

Отдельного поиска над списком нет. Все поддержанные текстовые критерии, статусы, даты и настройки страницы находятся в одном сворачиваемом блоке. Условия отправляются вместе, с семантикой AND серверного API; поиск по части строки остаётся серверным. Поле ID экземпляра фильтрует каталог при применении формы; маленькая кнопка рядом открывает известный ID без изменения списка, в том числе при недоступном API каталога. Кнопка сообщает назначение в подсказке.

Каждое применённое условие отображается компактным чипом с индивидуальным удалением; подсказка раскрывает полный текст. Предфильтр точной версии — обычный `definitionId` с названием и версией на чипе, а не отдельное скрытое ограничение. Контекстный переход задаёт его для runtime/history/jobs, но последующее удаление или сброс действует на текущую вкладку. У каждой вкладки независимые применённые условия и пагинация. Сброс определений возвращает последние версии; индивидуальное удаление этого чипа включает все версии.

Все сведения справа прокручиваются одним контейнером вместе с записями. У экземпляра это `runtime-instance-panel`; вложенные сведения и списки вертикального скролла не имеют. У сводки и отдельных заданий контейнер — сама панель сведений. Длинные текстовые значения сохраняют собственную ограниченную область просмотра; список записей не сжимается под метаданными при небольшой высоте окна.

Выделение элемента использует тонкую сплошную рамку Outline того же diagram-js, что и редактор, без тени и пунктирной обводки. Цвета состояния внутри рамки сохранены. Для стрелки рамка остаётся видимой в мониторе, поскольку инструментов редактирования/маркеров концов здесь нет.

Подсказка сводки содержит состояние, числа, время и ограничения; цветовая легенда остаётся только над схемой. Загрузка сводки и схемы независима: медленный ответ статистики не задерживает импорт SVG, работу с холстом и просмотр XML. Это проверяется отдельным E2E с задержкой сводки.

## Последствия

Закрытые фильтры занимают одну строку управления и место применённых чипов. Вкладки источников расположены сеткой 2 × 2, чтобы подписи помещались в узком каталоге. Форма фильтров имеет собственную ограниченную высоту, оставляя доступ к результатам; это отдельная левая панель, правило единого скролла относится к правым подробностям.

Новых зависимостей и изменений IPC/API нет. Незавершённая запись history не объявляется текущей runtime-позицией. Метаданные, XML и сводки сохраняют независимые состояния загрузки и ошибки.
