# 0003. Generic XML для Flowable

Статус: принято. Дата: 2026-10-08. Уточняет ADR 0002.

## Контекст и проверка

Регистрация Flowable moddle namespace с неполным descriptor приводит к `unknown type` на неизвестных тегах этого же namespace. На реальных схемах затронут `flowable:is-default-flow`. Кроме того, расширение BaseElement свойствами, совпадающими с BPMN, создаёт конфликт наследования. Generic XML неизвестных namespaces сохраняется стандартным bpmn-moddle без этих потерь.

## Решение

Не регистрировать Flowable namespace в moddle. Flowable-атрибуты хранятся в `$attrs`, extensionElements — в generic элементах. Реестр форм отвечает за применимость и UI типов; адаптер меняет `$attrs` и generic elements через команды. Boolean хранится строкой XML, пустое значение означает удаление атрибута.

## Альтернативы

Полный собственный descriptor потребовал бы синхронизации со всеми версиями Flowable и пользовательскими расширениями. Динамическая генерация descriptor сложнее generic representation и создаёт риск конфликтов имён.

## Последствия

При появлении новых тегов не требуется обновление модели. Удобные формы добавляются независимо от сериализации. Реальные схемы проходят два последовательных roundtrip без потери расширений. Стандартные BPMN свойства остаются типизированными moddle-свойствами.
