# 0046 — Точки отсчёта и статусы изменений документа

Принято: 12 ноября 2026 года. Уточняет [0041](0041-sessions-and-external-files.md).

## Решение

Локальные правки и необходимость сохранить работу определяются отдельно. Для схемы без файла исходным состоянием считается её модель после первой сериализации редактором. Для привязанной схемы — последняя сохранённая модель. Открытие, выделение элемента и различия форматирования при первоначальном импорте сами по себе не являются правками.

Дубликат получает собственную точку отсчёта независимо от изменений источника. `savedXml: null` до первого снимка позволяет учесть нормализацию нового редактора. Если скопирован неприменённый XML, он сохраняется как черновик и как `baselineDraft`: его наличие не окрашивает новую копию в синий. Последующие изменения модели или черновика сравниваются с этой точкой отсчёта. Отмена возвращает исходный цвет; отмена или применение скопированного черновика меняет состояние копии. Применение полного XML, как и прежде, сбрасывает историю команд модели. Черновик, полностью совпадающий с моделью, удаляется: полная отмена XML-правок не должна создавать скрытые неприменённые изменения при следующем редактировании схемы. Это правило действует при вводе, синхронизации модели и восстановлении сессии.

`baselineDraft` — необязательное поле снимка документа в сессии и резервном recovery. Восстановление не меняет исходную точку отсчёта. Снимки без этого поля читаются по прежним правилам; старые дубликаты с `savedXml: ''` сравниваются с их `diskXml`. Успешное сохранение или перезагрузка очищает `baselineDraft` и задаёт базу сохранённой модели. Отмена или ошибка записи её не меняет.

## Индикация и защита работы

| Состояние | Точка | Подтверждение закрытия вкладки |
| --- | --- | --- |
| Без файла, без правок | Серая | Да |
| Без файла, с правками | Синяя | Да |
| Файл, без локальных и внешних изменений | Нет | Нет |
| Файл, с локальными правками | Синяя | Да |
| Файл изменён, удалён или недоступен, локальных правок нет | Жёлтая | Нет |
| Внешнее изменение и локальные правки | Красная | Да |

Неприменённый XML также защищается при закрытии. Общая проверка несохранённой работы используется вкладками, окном и сводкой сессии. Массовое закрытие запрашивает одно подтверждение. Окно перед закрытием записывает свежий снимок сессии.

Команды сохранения, дублирования, перезагрузки и закрытия сначала снимают фокус с поля свойств, чтобы применить ввод, затем асинхронно считывают модель. Решение о подтверждении не опирается на отстающий React-снимок. Неуспешное получение состояния не закрывает вкладку.

Подсказки вкладок используют одинаковый порядок: имя, путь при наличии, состояние схемы, неприменённый XML, состояние внешнего файла. Для схемы без файла используется «Схема не сохранена в файл». Инструкции о будущем сохранении и подтверждении закрытия не показываются. Описание точки и тултип используют одни сведения; недоступность файла не выдаётся за изменение его содержимого. Монитор обозначается как доступный только для чтения, главная не получает файловых статусов.

## Проверка

Проверяются копирование изменённой модели и XML, независимые Undo/Redo, восстановление исходных цветов из сессии, сохранение и его отмена, подтверждения одиночного и массового закрытия, внешние изменения и удаление. Отдельный сценарий Electron проверяет команды при незавершённом вводе в поле свойств. Результаты — в [протоколе проверки](../validation-tab-status.md).
