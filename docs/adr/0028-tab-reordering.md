# 0028 — Перестановка вкладок

## Контекст

Единый список вкладок содержит документы, мониторы и стартовые страницы. Пользователю нужен произвольный порядок без изменения содержимого и истории редактирования.

## Решение

Перестановка меняет только массив вкладок в useTabs и сохраняет activeId. Документы и мониторы сохраняют стабильные React key и не пересоздаются. HTML drag-and-drop показывает сторону вставки; массив обновляется при drop. Перетаскивание файлов остаётся отдельным действием. Клавиатурный эквивалент — Ctrl+Shift+Left/Right при фокусе на вкладке. Обычные стрелки продолжают переключать вкладки.

## Альтернативы и последствия

Отдельная библиотека DnD и сохранение раскладки между запусками не требуются. Порядок живёт в текущем окне; закрытие активной вкладки выбирает соседа в актуальном порядке. Отмена drag не меняет состояние.
