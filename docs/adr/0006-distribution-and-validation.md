# 0006. Поставка и независимая проверка

Статус: принято. Дата: 2026-10-08.

## Контекст

Пользователь выбрал Linux и Windows с приоритетом Linux AppImage. Требуется проверять готовое приложение, а не только библиотеки сериализации.

## Решение

electron-builder собирает AppImage x86_64, Windows NSIS предусмотрен отдельно. Runtime — Electron с native sandbox и contextIsolation. Свой SVG-значок компилируется в PNG через resvg; build tools не входят в runtime. Файловые аргументы передаются существующему окну, приложение использует single instance lock. Namespace с именем процесса desktop фиксируется для ассоциации окна с launcher.

Playwright проверяет UI, Electron preload/native save/CLI и извлечённую готовую AppImage с включённым Chromium sandbox. Извлечение позволяет проверить артефакт в среде без FUSE. Дополнительная Maven-утилита сравнивает original/export после преобразования в модель Flowable 7.2, исключая графический DI. Java не требуется пользователю приложения.

## Последствия

AppImage требует FUSE для обычного монтирования либо запуска с extract-and-run (первым аргументом). Интеграция launcher/MIME в файловом менеджере зависит от установки AppImage системой пользователя. Windows/macOS нельзя объявлять проверенными по Linux-сборке. Проверка Flowable-конвертером не исполняет delegates и не заменяет тест запуска процесса в движке.
