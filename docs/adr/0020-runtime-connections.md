# 0020 — Подключения к движкам и чтение состояния

Статус: принято.

## Контекст

Нужно просматривать развёрнутые определения, экземпляры, executions, переменные и dead-letter jobs. Локальный редактор остаётся самостоятельным. Действия администрирования не входят в этот этап.

## Решение

Подключение хранит название, движок, REST root и вариант авторизации. Общие контракты рассчитаны на Flowable и Camunda 7; реализован адаптер Flowable REST 7.2. UI не получает универсальный HTTP-клиент: preload предоставляет конкретные операции чтения, main проверяет источник IPC, параметры, ответы и выполняет только GET к выбранному REST root. Адреса из ответов сервера не используются. Редиректы запрещены, TLS-проверка не отключается; запрос имеет таймаут, ответ — предел размера.

Профили сохраняются атомарно в каталоге пользователя Electron. Пароли и Bearer-токены при явном выборе пользователя шифруются через Electron safeStorage. Linux backend basic_text не считается защищённым хранилищем. Без доступного хранилища секрет живёт только в памяти main до завершения приложения. Смена адреса или вида авторизации не переносит старый секрет. Renderer получает только признаки наличия секрета; настройки, переменные и ответы не отправляются в Git или восстановление редактора.

Удалённая схема открывается в отдельном просмотрщике bpmn-js NavigatedViewer. Состояние исполнения отображается маркерами и overlays без изменения XML и command stack. Из экземпляра загружается точный processDefinitionId. Для редактирования создаётся локальная копия. Повторное получение состояния не пересоздаёт холст. Частичные ошибки чтения и ограничения объёма показываются явно; недоступные dead-letter jobs не означают отсутствие ошибок.

## Альтернативы

- Запросы из renderer: усложняют CORS и раскрывают секреты UI. Отклонено.
- Изменение цветов BPMN DI для подсветки: загрязняет модель и историю редактирования. Отклонено.
- Универсальный proxy и административные REST операции: расширяют полномочия без необходимости. Отклонено.
- Один жёстко заданный сервер: не покрывает несколько окружений и движков. Отклонено.

## Последствия

Нужен доступный REST API и права чтения repository/runtime/management. Поддержаны none, Basic и Bearer; автоматический OAuth/SSO обмен пока не включён. Отдельное тестовое приложение с Flowable, H2 и оригинальными схемами проверяет реальные REST ответы и запуск независимых экземпляров. Оно не входит в дистрибутив. Новые Java зависимости служат только тестовому стенду; runtime-зависимости редактора не добавляются.
