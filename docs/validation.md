# Проверка релиза 0.6.0

Кандидат 0.6.0 подготовлен из локально проверенных изменений монитора; предыдущий релиз сохранён в [протоколе 0.5.0](archive/validation-0.5.0.md). После локальных проверок основная ветка и тег должны пройти нативную матрицу Linux/Windows. Результаты CI и опубликованные артефакты будут добавлены после выпуска; до этого новые Windows-проверки не заявляются.

## Локальная проверка кандидата

Linux x86_64: strict TypeScript, ESLint и 111 unit-тестов; 92 E2E успешно, 18 ожидаемых пропусков; 33 Flowable runtime-теста. AppImage 0.6.0 собрана и запущена с sandbox в двух E2E; семь файлов out, версия, штатные примеры и лицензии совпадают с app.asar/ресурсами. Официальные Flowable converter 7.2 и Camunda Model API 7.24 проверили экспорты. GitHub Markdown API сохранил галерею обеих README и закрытый русский details релиза.

## Покрытие

- Поиск завершённых и продолжающихся экземпляров Flowable на точной развёрнутой версии BPMN; фильтры business key, дат и состояния.
- Журнал и схема связаны в обе стороны; отдельные проходы, циклы, multi-instance, вложенные и вызванные процессы, исполнители и причины прекращения.
- Сохранённые переменные с областями task/execution. Неполные выборки обозначаются; отказы API и поздние ответы не создают ложного полного/пустого состояния.
- Общая схема истории и runtime с подтверждёнными зелёными позициями, отдельными ошибками источников и совмещённым экспортом SVG/PNG.
- Карточки родителя/ребёнка, изолированные переходы назад/вперёд, подсказки назначения, команды боковых кнопок мыши.
- Сворачиваемые панели, уведомление о новом выборе без раскрытия, компактная легенда/время и доступные с клавиатуры подсказки.
- Настоящие wheel-события над бейджем: обе оси, Shift и Ctrl; логотип не перекрывает кнопки панелей. Обе темы, размеры окна 1500 и 1050 px.
- Регрессия редактора: copy/paste между схемами, перестановка вкладок, независимый undo/redo, BPMN default, XML/расширения, экспорт, файлы, recovery, темы и локализация.

## Границы подтверждения

История зависит от сохранённых данных и прав Flowable. Снимки не транзакционны; отсутствие endTime не подтверждает активность, а окончание не доказывает успех. Сохранённые переменные — последние значения, не воспроизведение по времени. Переходы не достраиваются без записанных sequence flows.

Flowable/H2 использует оригинальные MIT-схемы и условные данные, пользовательские материалы в CI и дистрибутив не входят. Системные команды боковых кнопок проверяются через настоящее окно Electron; физическое устройство не нажимается. Проверки Windows-приложения не заменяют ручную приёмку installer/portable и ассоциаций. Windows EXE не подписаны, macOS не поставляется.
