Подготовка патч-выпуска 9 ноября 2026 года. Пользователь подтвердил ручную проверку панели вкладок и разрешил публикацию. Код приложения проверен на `bb7acb6`; после него меняются версия, скриншоты, сценарии их съёмки и документация. Повторные локальные тесты пропущены по прямому указанию пользователя.

## Покрытие изменений

- Плюс сразу за последней вкладкой без переполнения; при переполнении — у правого края.
- Стрелки поверх непрозрачной части затухания, постоянная ширина области при появлении и исчезновении кнопок, активная вкладка с учётом места под стрелками.
- Обычное и горизонтальное колёсико, Shift, прокрутка над стрелками, закрытие средней кнопкой с отменой и подтверждением для несохранённой схемы.
- Обновлённые кадры редактора, стартовой страницы, Camunda, монитора и истории; главный кадр со сплитом двух тем.

## CI и артефакты

Результаты матриц main/тега, происхождение артефактов и скачанные контрольные суммы фиксируются после публикации.

Нативная проверка Windows Server не заменяет ручную приёмку installer/portable и файловых ассоциаций Windows 10/11. Windows EXE не подписаны; macOS не поставляется. Пользовательские схемы и подключения в Git и дистрибутив не входят.
