## Покрытие изменений

- Серый индикатор схемы без файла, синяя индикация правок, самостоятельная точка отсчёта дубликатов и сохранение состояний при восстановлении сессии.
- Подтверждения закрытия и удаления несохранённой работы, свежая модель после ввода в свойствах, устранение скрытого XML-черновика после полной отмены правок.
- Единые тексты подсказок вкладок на русском и английском, точное описание состояния внешнего файла.

## Уточнение E2E для Windows

Первый релизный CI остановлен после отказа сценария повтора XML-правок: тест использовал `Ctrl+Shift+Z`, дополнительное сочетание CodeMirror только для Linux. В сценарии заменено на `Ctrl+Y`, стандартное для Linux и Windows; код приложения не менялся. Точечный браузерный сценарий повторён локально, полный локальный набор не перезапускался. Неопубликованный тег 0.7.3 будет указывать на коммит с исправленным тестом; повторная матрица проверит обе платформы.

## Границы подтверждения

Нативная проверка Windows Server не заменяет ручную приёмку installer/portable и файловых ассоциаций Windows 10/11. Windows EXE не подписаны; macOS не поставляется. Пользовательские схемы и подключения в Git и дистрибутив не входят.
