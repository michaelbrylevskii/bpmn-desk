Дата подготовки: 10 ноября 2026 года. Пользователь подтвердил ручную проверку и разрешил публикацию патч-релиза. Код приложения проверен на `fd5e2b5`; подготовка релиза меняет версию и документацию. Повторные локальные тесты пропущены по прямому указанию пользователя.

## Покрытие изменений

- Общая для окон фоновая проверка GitHub при запуске и каждые шесть часов, ручная проверка и фиксированная ссылка последнего релиза.
- Одинаковая геометрия кнопки версии, анимация минимум одну секунду, reduced motion, результат и время проверки в подсказке; ошибка и таймаут без всплывающих уведомлений.
- Окно «О приложении»: автор Mikhail Brylevskii, участие OpenAI Codex, ссылки, лицензия, версия и сведения о работающем приложении.

## CI и артефакты

Релиз ожидает матрицу Linux/Windows и публикацию трёх дистрибутивов с `SHA256SUMS`. Результаты и контрольные суммы будут записаны после завершения workflow.

## Границы подтверждения

Нативная проверка Windows Server не заменяет ручную приёмку installer/portable и файловых ассоциаций Windows 10/11. Windows EXE не подписаны; macOS не поставляется. Пользовательские схемы и подключения в Git и дистрибутив не входят.
