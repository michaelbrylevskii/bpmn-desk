## Покрытие изменений

- Точный снимок схем и неприменённого XML, порядок и активная вкладка, выделение и viewport; мониторные вкладки с местом просмотра и фильтрами, свежие ответы после восстановления.
- До 15 недавних сессий, именованные закрепления вне лимита, inline-ввод имени и продолжение рабочего набора; устойчивое скрытие предложения и удаление снимков.
- Отдельные окна при занятом рабочем пространстве, через меню и `Ctrl+Shift+N`, повторный запуск без файла; фокусировка открытой сессии, файловые разрешения и независимое закрытие.
- Внешние изменения и удаление файлов, статусы вкладок и подсказки, перезагрузка, отмена/копия/перезапись/повторное создание, проверка ревизии и сохранение модели при некорректном XML.
- Меню вкладок, компактная стартовая страница, переполнение вкладок, обе локализации и темы; SVG/PNG, уведомление с открытием папки и два PNG в нативном меню.

## Границы подтверждения

Undo/Redo и цепочки навигации между запусками не сохраняются. Подключения общие для окон, их секреты не входят в сессии; ответы монитора читаются заново. Нативная проверка Windows Server не подтверждает ручную установку и файловые ассоциации Windows 10/11. Windows EXE не подписаны; macOS не поставляется. Пользовательские схемы и подключения в Git и дистрибутив не входят.
