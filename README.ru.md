## Возможности

- **Визуальный редактор.** Элементы и связи BPMN, вложенные подпроцессы, свойства Flowable/Camunda 7, пользовательские атрибуты и расширения.
- **XML.** Подсветка синтаксиса, поиск и замена, переход к выбранному элементу, отдельное редактирование расширений и проверка сохранности данных.
- **Рабочее пространство.** Независимые вкладки и undo/redo, недавние файлы, drag-and-drop, CLI, восстановление черновиков и защита от внешних изменений файла.
- **Монитор Flowable.** Сохранённые подключения с настраиваемым таймаутом, определения процессов с последними версиями по умолчанию, экземпляры, executions, задачи и переменные. Единые поиск и фильтры каталогов. Dead-letter, stacktrace, заметное выделение и ограниченная сводка с автозагрузкой и компактной подсказкой состояния. Автосводка отключается для подключения; общий авторефреш обновляет и загруженные сводки. XML доступен с подсветкой и поиском, только для чтения.
- **История выполнения.** Поиск завершённых и продолжающихся экземпляров Flowable; отдельные проходы шагов, циклы, multi-instance и вызванные процессы. Общая схема совмещает зафиксированные проходы и подтверждённые позиции runtime; вкладки «Текущее состояние» и «История выполнения» находятся справа. Переходы назад/вперёд по определениям, экземплярам и заданиям доступны в тулбаре монитора; подсказка показывает назначение. Несколько записей журнала можно раскрыть без фильтрации; прямой выбор элемента схемы фильтрует его проходы.
- **Экспорт.** SVG и PNG с белым/прозрачным фоном; монитор экспортирует метки состояния.
- **Интерфейс.** Английский и русский языки, системная/светлая/тёмная тема, масштабирование интерфейса и схемы.

Локальный редактор не требует аккаунта, сервера или загрузки файлов в облако. Монитор подключается к выбранному REST API и предоставляет только чтение.

Элементы можно копировать между схемами одного окна: выдели элементы на холсте, нажми `Ctrl+C`, переключись на другую схему, щёлкни по свободному месту холста для фокуса, нажми `Ctrl+V` и щёлкни в месте вставки. Вставка отменяется в принимающей вкладке. Буфер элементов не передаётся в другие окна или внешние редакторы; внешние процессы, формы и ресурсы автоматически не переносятся.

Вкладки схем, мониторов и стартовой страницы можно менять местами перетаскиванием. С клавиатуры: установи фокус на вкладку и нажми `Ctrl+Shift+←/→`. Порядок действует в текущем окне до его закрытия.

## Поддержка движков

| | Редактирование | Мониторинг |
| --- | --- | --- |
| BPMN 2.0 | Стандартные элементы и свойства | — |
| Flowable | Реализации задач, исполнители, async/retry, listeners, forms, in/out | REST 7.2: состояние, переменные, dead-letter |
| Camunda 7 | External tasks, listeners, input/output, forms, connectors, DMN/call bindings, multi-instance | — |

Неизвестные расширения доступны через атрибуты и XML. Профиль определяется по namespace URI; автоматической конвертации между движками нет.

Поток по умолчанию: выбери стрелку → «Основные · BPMN» → «Поток по умолчанию», либо выбери исходную задачу/шлюз и задай `default`. Оба поля меняют стандартный `default="ID_стрелки"` исходного узла, поддерживаемый Flowable и Camunda 7. Дополнительный `flowable:is-default-flow` не создаётся и не используется редактором как замена `default`.

## Скачать

[Последний релиз](https://github.com/michaelbrylevskii/bpmn-desk/releases/latest) содержит **AppImage для Linux x86_64**, **установщик и portable для Windows x64**, а также `SHA256SUMS`. Node.js и Java для запуска не нужны.

```bash
chmod +x BPMN-Desk-*.AppImage
./BPMN-Desk-0.6.0-x86_64.AppImage
```

Без FUSE: `--appimage-extract-and-run` первым аргументом. Windows EXE не подписаны; macOS пока не поставляется.

## Границы

- Для визуального редактирования нужен BPMN DI; автоматической раскладки нет. XML при сохранении может менять форматирование.
- Редактор не исполняет процессы и не предоставляет deployment/retry. DMN/CMMN, Camunda 8/Zeebe и внешние дизайнеры форм не поддержаны.
- Для истории нужны сохранённые данные Flowable и доступ к API. Снимок загружает до 1000 записей шагов, 100 дочерних экземпляров и 100 сохранённых переменных; неполнота обозначается явно. Переменные содержат последние значения, а не значения на выбранном шаге. Снимок не транзакционен; для подсветки стрелок нужны записи переходов. Runtime Camunda 7 не поддержан. [Подробности API](docs/runtime-monitor.md).
- Переходы назад/вперёд хранят до 100 адресов в каждом направлении отдельно для каждого монитора, только в памяти. Смена подключения сбрасывает навигацию. Боковые кнопки мыши используют системные команды Electron; поддержка macOS ещё предстоит.
- Локальные файлы — до 20 МБ. PNG — до 16 384 px на сторону и 32 млн пикселей; для крупных схем доступен SVG.
